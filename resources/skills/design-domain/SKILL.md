# 空间设计专业分析

本 Skill 提供建筑与空间设计的判断方法，不提供当前项目事实。目标是让结论既有专业水平，又能追溯到项目资料。

## 决策入口

- 当前任务需要判断场地、建筑、室内空间、功能、动线、指标、图纸或方案时使用本 Skill。
- 任务只涉及文件格式操作时，直接读取对应 CAD、PPTX、DOCX、XLSX 或 PDF Skill。
- 需要在多份任务书、指标表、CAD、图片或汇报材料之间选择依据时，读取 [专业来源路由](references/source-routing.md)。
- 需要精确分析相邻、包含、入口、路径连续性、人车流线或空间冲突时，读取 [空间与动线分析](references/spatial-circulation-analysis.md)。

## 专业证据边界

- 项目事实只来自当前用户原话和成功读取的项目资料。项目资料可以由用户或 AI 创建。把“资料直接可见”“由事实支持的专业判断”“仍待确认”分开表达。
- 不把文件名、目录名、未读取文件、低清总览或 Skill 经验当成项目事实；不补写项目资料没有的尺寸、方位、用途、规范、结构和设备条件。
- 按结论所需精度选原件，不按读取便利：几何、图层与标注优先 CAD，条款与要求优先原文，低分辨率图片只用于补充其中直接可见的视觉信息。
- 关键权威来源尚未读取时必须继续查找；确实找不到就明确缺失并停止对相关指标下结论，不得用“常见值”、经验上限或猜测替代。
- 图纸或 CAD 原生文字可证明标签、编号和图名；同一 Layout 的图形与局部视图用于证明位置、边界和几何关系；任务书或正式说明更适合证明委托条件与设计要求。
- 指标和面积结论优先回到当前方案的数据表或可核算原始数据。汇报、展板和方案说明只有实际包含同一指标时才可交叉核验。
- 法规数值必须通过可用法规检索能力取得适用版本并保留条文来源；检索不到就说明限制，不凭记忆宣称合规。
- 当前用户明确变更优先于项目历史默认。历史 `rejected` 只表示不默认采用，不能成为拒绝本轮明确需求或重复澄清的理由。

## 来源职责

- `semantic_authority`：证明文字条件、标签、用途、指标或明确约束。
- `geometry_source`：证明边界、位置、距离、坐标和空间关系。
- `visual_reference`：证明照片、效果图、展板或图纸像素中直接可见的构成。
- `style_reference`：约束风格与表达方向，不自动承担项目数值和几何事实。

一份项目资料可承担多项职责，但每项证据都要绑定能直接回答它的来源。来源互不依赖时可以在同一响应中并行读取；达到最小充分证据后停止扩读。

## 常见专业判断

### 场地、总图与指标

- 先区分说明性条件、汇总数据和几何关系，再为每类问题选择相应原件。
- 方案现状值优先查总图、指标表或展板表格，控制阈值查任务书；候选中同时存在这两类职责时分别纳入并交叉核对，不从低清总览图目测数字。
- 总览用于理解整体与定位候选区域，不能证明细小标注不存在。控制线、宗地编号、边界和连续关系没有看清时，转向保留原生文字、图层或矢量关系的来源。
- 多份当前图纸覆盖不同分区、组团或专业时，只读取能够闭合当前证据缺口的原件；不得抽一份代表全套，也不得按固定数量机械扩读。抽样页不能冒充完整覆盖——全局或演变结论必须覆盖到相关的每个 panel/frame。
- 数值冲突时报告各自来源、版本和适用范围，回到计算口径或更直接的数据权威，不静默择一。
- 派生值必须保留单位、作用域、阶段、组成项和公式；地上/地下/总量等不同口径不得先合并再反推。

### 空间、功能与动线

- 先建立空间名称、功能、相邻关系、入口、路径和硬约束，再判断冲突与优化机会。
- 主要问题按“事实—影响—建议—确定性”表达；建议必须能落到空间调整、图纸修改或下一步核验。
- 路径连续、疏散、净宽、无障碍或人车关系需要精确证据时再加载专项参考；概念首版不为不存在的精度设置门槛。

### 多版方案与设计推敲

- 用户明确说明存在多版方案时，可比较各原件或独立分面中可见的轮廓、布局、界面、功能和体量差异。
- 缺少日期、版本号或说明文字时，阶段先后、调整动因和设计意图只能标为专业推断，并说明可由会议纪要或设计记录校准；没有标题或版本号就不得编造先后顺序。
- 定性形态比较不要求测绘级坐标；只有用户要求精确测量、落位或施工关系时才下钻几何。

### 首版设计表达

- 用户要求“先出一版”且未指定审美参数时，采用可逆的专业中性默认继续：主体完整、空间层级清楚、视角易读、文字不遮挡关键信息。
- 有明确风格参考就沿用其可观察表达方法；没有参考时不虚构品牌、材料、结构或项目背景。
- 只有缺失信息会改变核心项目事实、突破硬约束、扩大外部影响或触发不可逆动作时才阻塞澄清。色调、镜头、表现强度和装饰密度通常可以在下一版调整。

## 工作流

1. 明确本轮目标、必要来源、证据要求、成品和完成条件。
2. 读取会改变结论的最小充分原件；可信解析结果要保留来源、定位和能力限制。
3. 只采用能够回到原件和具体定位的直接事实；未回答的问题保持未解决，不用常识补齐。
4. 形成专业内容模型：项目条件、空间/功能模型、主要问题、影响、建议和待确认项。
5. 正式成品按对应文件 Skill 制作并调用 `deliver`；确定性检查不等于独立审美或内容评审。

## 默认输出

1. 已确认的项目条件；
2. 与任务相符的空间、功能、指标或方案判断；
3. 主要问题、定位证据及影响；
4. 分优先级的可执行改进建议；
5. 待补资料与无法判断项；
6. 实际检索到的规范来源与适用前提（如涉及）。
