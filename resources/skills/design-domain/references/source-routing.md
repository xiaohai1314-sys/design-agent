# 专业来源路由

只在任务需要从多份项目资料中选择、核对或补查来源时读取本参考。

## 来源职责

- `semantic_authority`：任务书、正式说明、原生图纸标签、当前方案数据表等能直接证明文字或数值事实的原件。
- `geometry_source`：原生 CAD、测绘图或保留几何关系的图件，用于边界、位置、距离和空间关系。
- `visual_reference`：照片、效果图、展板和图纸像素，用于直接可见的构成与表现。
- `style_reference`：用户指定的风格与表达参照，只约束视觉方向，不自动承担项目数值或几何事实。

一个来源可以回答多项证据，但每项证据必须明确绑定能直接回答它的来源。用户或 AI 创建的文件在成功读取后都可以作为项目资料；文件名、目录位置和解析产物路径本身不是内容事实。

## 选择原则

1. 用户点名的原件优先。没有点名时，按问题所需来源职责选择最小充分集合。
2. 说明性条件优先使用委托文件或正式说明；图纸原生标签可由可信 CAD 解析证明；几何关系回到原生图件。
3. 汇总指标优先使用当前方案的数据表。只有转录或版本混用会改变结论时，才增加一份独立编制且包含同一指标的来源交叉核验。
4. 图纸总览用于定位候选区域，不能证明细小标注不存在。精确标签、编号、边界或连续关系未确认时，补读保留原生文字、图层或矢量关系的来源。
5. 多份独立原件互不依赖时可以并行读取；补查只针对仍未满足的证据，不按固定文件数量或目录形态扩读。
6. 来源冲突时保留各自原文、版本和适用范围，不静默择一，也不把不确定项升级为项目事实。

## 常见边界

- 用户说明存在多版方案时，可以比较各原件中可见的轮廓、布局和组织差异；缺少日期或版本号时，先后顺序、动因和意图只能标为专业推断。
- 灵感和定性形态比较不要求测绘级几何；只有用户明确要求精确测量、落位或施工关系时才下钻坐标与尺寸。
- 图片只确认像素中能直接观察的内容；CAD 解析文字证明原生标签，CAD 视图证明同一布局内的空间关系。
- 直接读取 `.zmo/` 中间产物不能替代原件；只有带可信解析血缘的产物才能归回对应来源。
