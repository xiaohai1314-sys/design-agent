# 底图审改

## 审图诊断

对照用户原图与草图，逐项指出存在问题的空间与墙端、门洞或家具。先核实用户想改变的范围、现有出入口、关键设备和哪些结构须保留。不能从图上确认结构性质、排水或尺度时保留现状，并说明具体待核点。

## 沿用布局做表达

仅上色、换表现或完善图例时，沿用原图的几何、布局、家具和设备。使用全图一致的二维正俯视、门窗符号和房名，按[仅上色或换表现](image-generation.md#仅上色或换表现)选择表达。

## 局部优化

沿原图定位要改的区域，使用原图已有墙端、门洞或柱作为参照。只改影响本轮功能或通行的已确认可改部分。开门、家具摆放与通路一起核对；各对象完整，门扇两端与实际门洞接合。通常沿[原图直出](image-generation.md#沿原图直出)生图，位置易错时才用同画幅标注。需要尺寸或原图内容逐像素保留时，只在可靠对位且接缝避开完整对象的前提下做[局部恢复](fixed-plan.md#局部恢复原图)。

## 售楼图彩平

用途不明的凹位、灰区及其分隔沿用原状。从原图用可辨入户沿实际门洞核对各区域能否到达。明确是户内且能进出的区域再安排家具。公共楼梯、电梯井、公共通道和独立入户按原图保留。首轮解决可确认的布局，列出使用待核区所需的条件。

### 需原像素保护的售楼图局改

用户明确要求区外保持原像素时，按[固定底图编辑](locked-plan-edit.md)核对原图、改区与保护项。复查准备交付的实际文件，逐处核门洞、标注和整件家具，并说明精度或功能缺口。
