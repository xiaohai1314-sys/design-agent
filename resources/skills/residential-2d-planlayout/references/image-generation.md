# 生图参数和同画幅引导

> 本机只有一张参考图的通道：有底图时用 `edit_image_with_ref(reference_image_path, prompt, image_name)`，纯文字题用 `generate_image(prompt, image_name)`。下文「第一张 / 第二张」「query」「image_urls」按 [SKILL.md 的本机生图工具对照](../SKILL.md#本机生图工具对照先读) 换算：需要定位时只传同画幅引导图，在 prompt 里说明标记用途并要求成图去除标记；否则只传原图。

## 生图参数

以下图片顺序适用于常规首轮和整图返修。固定底图编辑、跨层定梯和尺寸图沿用各专项流程规定的生图底图、裁切与贴回参数。

按主流程确定表现、参照图、不可改墙段、实际通路和家具落位。同一墙面先标出开口与两侧门垛，再指定柜段的起止；柜体画不下就改落位。局部尺寸以横纵两个原尺寸为准。另做分析图时用核过的布置图作几何参考，只叠说明并逐房对齐。返修以待修图为第一张、干净原图为第二张，在 query 指明局部改动，按原图核结构和保留的尺寸；纯文字题沿用已知尺寸。

## 最小引导

在原图只标本案易错的局部，例如「电梯两侧公区留空」「凹口到此处为室外」「此段墙接齐」「只从该原门洞通行」。将标签放在图面空白处，用引线定位真实墙端、门洞两端或室外边界，避免盖住原墙、窗、尺寸和标高。多稿共用引导。用户明确要求外边界红线时，可以沿完整户型外边界示意，保留原开口可读。

用原图像素坐标，左上为原点。工作区 JSON 填 `labels`。每个标签写中心 `x`、`y`、`text`，可选的 `anchor: [x,y]` 指向相邻留白。需要外边界时可加 `outline`。文件输出用新的 PNG 名。已有引导可复用时直接复用。

```text
python -B "<Skill 路径>/scripts/prepare-plan-guide.py" --input-path "<原图>" --geometry-path ".design-agent/标注坐标.json" --output-path ".design-agent/平面引导.png"
```

脚本沿用原画幅，返回包含绝对路径的 `image_urls` 数组及尺寸。打开生成的标注图一次，确认构件没有被标签盖住。首轮以干净原图为第一张，标注图仅作第二张定位参考。在提示词中交代两图用途，成图去除辅助标记。

## 去门轨引导副本

在原图能准确分辨既有门洞、旧门轨或门扇，且题意明确允许开通时使用。先在原图放大看清每处原洞口的两端，确定只包含可去门线的矩形以及相邻需要保护的墙垛、柱、尺寸、标高及设备。门线和结构线重叠或性质不清时用最小引导标位置，沿用原图线条并说明待核条件。

用原图像素坐标，左上为原点。修复文件是一个 `repairs` 数组，每项用 `type: "clear"`、`rect: [left, top, right, bottom]` 和相邻同色空白的 `background: [x, y]`。保护范围文件写原图的 `originalSha256` 和 `locks`，每个保护区由 `points: [[x,y], ...]` 定义。深底图加 `background: "dark"`。

```text
python -B "<Skill 路径>/scripts/prepare-plan-guide.py" --input-path "<原图>" --opening-repair-path ".design-agent/门线.json" --opening-scope-path ".design-agent/保护范围.json" --output-path ".design-agent/开口引导.png"
```

打开副本，逐处检查旧门线消失、净开口连续，原墙垛与柱、尺寸和标高依然清楚。首轮以原图定结构，另附已核副本说明局部开口。交付前按原图复核保留项。

## 调用回执与失败

回执给出图片文件才算返图。缺参数或标注文件同名时，修正具体错误一次。引导仍无法制作时，选择原图为唯一参考并在生图请求中补充方位，交付时说明原因。

超时先核是否已有结果或在途。确认失败且可重试时，沿原请求和同一参考补救，仍有候选就先复核候选。仍无可读候选或服务不可用时，有底图就用标注脚本在副本上画出拟改门位、主要家具和通路，输出「布局示意」PNG；净尺寸明确的单房可按尺寸图脚本出图。若文件也无法生成，直接给出逐空间布局、关键落位与待核尺寸，说明缺图原因。交付前确认实际登记的图能打开，且对应已经核对的候选。

## 仅上色或换表现

按原图保留墙、柱、门窗、家具与设备的几何位置。各房保持同一套二维正俯视符号，风格参考只决定表现。原图本身为线稿时，只有用户明确要求彩平才着色。
