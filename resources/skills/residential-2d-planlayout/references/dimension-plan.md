# 单独交付坐标尺寸图或边界引导

用户另外要求可量的坐标尺寸图时使用本节。先排家具真实占位，留出入口、最紧的通路和实际使用面。用同一份毫米坐标生成单独的尺寸交付图。正式平面的画法由主流程选择，尺寸图和已选成图的空间关系需能互相核对。

用 `write_file` 保存 JSON，再执行一次。坐标以室内左上角为原点，横轴向右，纵轴向下。矩形写 `[左,上,右,下]`。本例只说明参数和参考画法，按实际任务补全家具和用途。

```json
{
  "width": 3600, "depth": 2900,
  "furniture": [
    {"label":"睡眠区","kind":"bed","rect":[400,0,1900,2000]},
    {"label":"工作台","kind":"desk","rect":[2950,0,3600,1400]}
  ],
  "openings": [
    {"kind":"door","side":"south","from":2200,"to":3050},
    {"kind":"window","side":"north","from":2050,"to":2900}
  ],
  "clearances": [
    {"label":"入户","rect":[2100,2000,3150,2900],"axis":"depth","minimum":850},
    {"label":"床侧通行","rect":[1900,0,2650,2000],"axis":"width","minimum":750}
  ]
}
```

- 家具 `kind` 可用 `cabinet/sink/cooktop/tall/island/table/chair/bed/desk/sofa/fixture/partition`。相邻的地柜分段独立标水槽、灶台或电器。座椅单独给矩形，`front` 填坐下时朝向。
- 边用图面 `north/east/south/west`，上下墙洞口从左量，左右墙洞口从上量。`door` 表示通行开口。有铰链或开启方向要求时同时核对门扇使用面。
- `clearances` 指已计划保持为空的矩形，例如柜门操作带、椅后拉出区和入口落脚区。最小值按家具型号、实际用法和题意选定。重点净空加 `"dimension":true` 标在图上。逐段连到要到达的地方，并看图核对开门、拉椅与通行能否同时发生。脚本检查录入的矩形，不替代整条实际路线的审图。
- 岛台与餐桌等家具共用狭窄通路时，给通路旁的活动餐椅填 `pullOut`（从图示座位向后拉出的毫米数），在需要持续通行的净空加 `"keepClearWithChairsOut":true`。脚本按椅背方向核对拉椅过程，虚线标示拉出范围；通路尺寸量到虚线外缘。只用于拉椅的空位可以被餐椅占用，通行另留。根据家具型号选择拉出距离，未给型号时在交付中说明假设，并核对转角是否接通。

```text
python -B "<Skill 路径>/scripts/rectangle-plan.py" --layout-path ".design-agent/layout.json" --output-path "01_尺寸布局图.png"
```

脚本在家具重叠、净空被占或入口缺少落脚空间时返回对应位置。只改冲突对象，输出使用新文件名。检查尺寸图与已选方案。虚线表示拉椅占位。尺寸以同源坐标图为准，图面长宽和家具比例按实际绘制比例核对。

## 已有边界引导的出图与核验

仅当用户另行要求边界图或明确指定使用边界图时，用给定两轴尺寸生成室内等比例红框。两条尺寸链可写入 JSON，出图后用于同批比选。

```text
python "<Skill 路径>/scripts/rectangle-guide.py" --width <横向尺寸> --depth <纵向尺寸> --output "plan-boundary.png"
```

最容易互相挤占的两至三件家具，可在同一份尺寸链 JSON 加 `"furniture":[{"label":"岛台","rect":[左,上,右,下]},{"label":"餐桌","rect":[左,上,右,下]}]`。坐标用室内左上角作原点、和尺寸链相同的单位，圈实际家具尺寸。尺寸链另留开柜和拉椅空间。引导命令加 `--layout "<尺寸链 JSON>"`，把这张带灰色占位的红框图直接传给生图。提示词让家具贴合各自灰框、开柜和拉椅区域留空，成图删除引导线。简单房间用原红框命令。

将绝对路径传给原生 `generate_image`。写清沿室内红框使用二维正投影、出图移除红线、家具分区及需要留空的位置。按主流程的线稿或彩平画法，用正俯视轮廓表达柜体和设备。入口画成贯穿墙厚的门洞，两侧可达。图上保留横竖总尺寸线，家具及净空尺寸随文字说明，最后核对标注与实际位置。

先打开同批候选，确认墙线与家具能按正投影俯视量取。能看见立式柜门正面、墙体立面或明显斜投影时，该候选作为表现参考。用两对平行墙的内缘量图，门窗中断处可延伸同一墙线。确认实际入口、指定家具、开柜和拉椅的净空后，从 `fitCandidates` 中挑符合图面条件的一张。墙内缘可见但自动检测没量出时，给这张图补一次手动 `innerRectPx`。草案里的家具落位按可用成图更新说明。只有一张候选时省去 `--also`。

```text
python -B "<Skill 路径>/scripts/check-rectangle-layout.py" "<候选一>" "<尺寸链 JSON>" --detect-inner-frame --also "<候选二>"
```

JSON 中 `width`、`depth` 和尺寸链使用同一单位。`chains` 包含 `width` 和 `depth`，两项均为沿各轴排列的 `{"name":"占用或空隙","size":数值}` 数组。默认超过 5% 的图面比例偏差需复核。尺寸链通过表示拟定数值闭合，家具、门扇和使用空间要按选中的成图核对。纵横拉伸会同时改变柜体、座椅与净空的比例。实画比例超差时，按[已知长宽布局](rectangle-layout.md#成图比例需要量图时)纠正四边和画幅后才考虑补图。复测实际调用 `deliver` 的那张 PNG，说明量到的净空及复尺项。仍有硬缺项时说明具体位置，交付最佳可读候选并标为复核稿，列出待复尺的尺寸。
