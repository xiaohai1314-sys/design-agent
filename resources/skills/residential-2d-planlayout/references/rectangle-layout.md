# 已知长宽的房间布局

纯文字布局题直接调用 `generate_image`。首图先写内框宽深和比例、用户给定的门窗方位、必需家具与最紧的使用净空。尺寸端点锚到实际内墙。内框和留白用同一单位，例如内框 160×100，四周各留约 20 单位，画幅约 200×140。只对影响布局的开口尺寸和开启方式作假设，图中简注待复尺。

默认二维正投影黑白线稿，按主流程选定彩平时才用配色。让主要家具、活动区和通路在整图上清楚可读，标注避开家具轮廓。图内优先放总尺寸、必要家具和决定布局的净空。高低床和阶梯柜画实际占位及上床方向。橱柜与岛台画完整台面轮廓，水槽和灶具嵌在俯视台面中，餐桌与座椅各画完整占位。风格用俯视图例和简短注记表达。

先辨净尺寸和外包尺寸，纯文字未说明时按室内净尺寸排布，交付时简述影响使用的假设。沿两轴合计限制布局的家具进深和通行留量，确认能放进给定长宽。把影响落位的连续尺寸链放入生图请求，例如沿同一剖切位置的贴墙柜深、柜前净空、岛台进深和对侧净空。图内标注总尺寸及关键净空，尺寸从实际墙线或物体边缘量起。桌边距和拉椅后的通道净宽分别核算。

窄厨房同时要岛台和独立餐桌时，先试沿长轴把两者分到备餐区和就餐区，避免在短轴上叠加两件家具与双侧使用空间。优先保住岛台的备餐面、餐桌可用席位和进门通道。需要压缩时先收掉岛台加座、非必要的岛台水槽或餐边柜，再调整家具朝向及尺寸。开柜、拉椅或主通行仍有冲突时，把发生冲突的状态和相应取舍写在方案里。

选定餐桌每一侧的座位类型。靠墙卡座先画实际入座方向、座面到桌边的关系及桌下腿部空间，检查桌腿有没有挡住滑入路线。图上只画出面贴面且桌下未知时，只标为拟设卡座，不把它计入已确认席位。活动餐椅分别标在哪几边，以及哪个桌端留空。没有指定席位数量时，先保证岛台和独立桌的使用空间，再添席位。出图后按实际可进入的座位计数。

## 成图比例需要量图时

从实际候选量两对平行墙的内缘，门窗断处延长同一墙线。需量图时可用 `check-rectangle-layout.py --detect-inner-frame`，自动取不到墙边时用 `innerRectPx` 量四边。按内框比例、给定门窗是否画对、必需家具能否使用的顺序选同批候选。硬缺项值得补图时，明确要修的内墙、开口或家具关系。仅有非关键图签和文字差异时优先交付已合格的图。尺寸或必要功能仍有偏差时，按主流程提交复核稿并写清偏差。
