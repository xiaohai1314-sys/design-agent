# 同底图多版像素保护

本页工具用于多案均有明确区外像素级保护要求的任务。常规多案按 [主流程](../SKILL.md#读图与定布局) 共用原图约束，确定实质差异后直接生图。使用本页工具时，逐版核对合成后的门洞、墙线、完整家具和通路。

## 逐版像素保留

有同一现状底图时用本节建共用保护范围、贴回和回执。各版保留原尺寸链和同一段固定外轮廓。登记前看实际整图和接缝。

1. **先定共用条件。** 同一原图只核一次不改的墙柱、外窗、入户、厨卫及公共楼电梯等相邻区域。用[固定底图编辑](locked-plan-edit.md)确定共用编辑和保护范围。用户要求原样保留的设施，将整个范围含门及设备从改区排除。对未确认用途或入口的灰区，按[售楼图范围](existing-plan.md#售楼图彩平)在首份共用复核写 `unconfirmedAreas`，覆盖该区与原分隔。居住人数按确认能进入和使用的房间安排，先排实际床位。各版开口不同时走[多版引导](#多版引导)。开口和固定范围相同，家具差异仅靠名称或相对方位即可表达时，可共用引导和回执。
2. **排出可用的差异。** 先给每版一个实际生活取舍，例如保有独立客厅、把家庭大桌作为活动中心、给多代居住留独立作息。逐版从原入户走到各房门，再检查实际床宽、双座、椅柜开启和需要的收纳容量。把关键对象和使用面标进实际可改区。比如书房双人桌若在已确认的书房段，出图提示也写「书房标框内沿侧墙摆双人桌」。拟沿窗布置时先确认窗前地面与书房连通，框包含窗前桌椅及使用面。新增独立房应能从公共区经实际门洞进入。需要增加房间时，先检查可达的房间能否换用途，或有足够面积和既有窗的公共空间能否分隔，各部分都留可达的门。门位确认可改时把完整门洞及门扇纳入本版回执。生图提示给出可确认的床位、房门及到达方式。
   窄房的床紧邻保留窗轨、墙或门扇时，先确定完整床体能在分隔同一侧落位，再核对床侧、床尾与进门路线。生图提示写清床头和床尾所在侧。已有引导可标床位，关键是贴回后完整床体与床旁通行都可辨认。
   多人版优先给最难安置的家庭成员排好床、出入口和独立使用条件，再用剩余面积组织起居。兼用区确有临时留宿需要时，分别核对日常和床展开后的使用状态。若要新增可关合的房间，在同一回执标隔断端点、接墙位置和门洞两侧的通路。保护区、既有窗和开门净空有冲突就重排。若只能做到可用的临时床位，图上写出真实用途和隐私取舍。
3. **先做出一张经过复核的图。** 首次只为一版调用 `generate_image`。提示词优先写每版必须成立的房间用途、家具数量、出入口与固定边界。额外岛台、咖啡角等可选项随实际空间取舍，确认未妨碍原需求即可收敛。按位置和功能挑首选，有同批另一张时写入 `alternate`。贴回首版后直接查 `verifiedPng` 与需要查看的局部图，房间、门和主要家具齐全就登记。剩余单处家具或门扇待修时，可用已经确认的保护和引导推进其它版，再一起复核。
4. **完成其余各版。** 从各自已预检的引导推进。同一批已有候选的各版用一次命令贴回。先看合并预览，对关键门洞、家具或接缝按需打开实际大图。逐版登记检查通过的 `verifiedPng`。某版需要修补时，可先登记其余可交付版本。只有房名或零星过程字要改时，沿用本版已核图纸，在受影响的局部清补一次或在同份交付里说明图上对应位置。新增房间的墙、门和到达如果画错，先修正落位和回执，再处理边角字样。

### 一次贴回候选

把已有候选路径写成 JSON 文件。首版时数组只放一项。候选、回执可用任务目录相对路径。开口或改区不同的版在条目中填写对应 `receipt`。
用 `write_file` 保存 JSON，然后单独运行下方命令。候选用生图工具返回的绝对路径，回执用预检返回的 `planReceiptPath`。

```json
{"variants":[{"id":"A","candidate":"两人.png","alternate":"两人-备选.png"},{"id":"B","candidate":"三口.png","receipt":".design-agent/三口回执.json"}]}
```

```text
python -B -X utf8 "<Skill 路径>/scripts/compose-plan-variants.py" --original-path "<用户原图>" --plan-receipt-path ".design-agent/共用回执.json" --candidates-path ".design-agent/候选.json" --output-directory ".design-agent/本批复核"
```

`previewPng` 用于浏览本批。直接打开 `verifiedPng` 看实际拟登记图，它已按回执中的 `crop` 裁好。需要原像素位置就打开带坐标的 `detailsPng` 或用 `composition.png` 复核。确认贴回后每个关键对象完整、独立房能通过实画门洞进入，再登记每版自己的 `verifiedPng`。标为待复核的版按 `reportPath` 和 `reviewPng` 定位缺项。自动对位失败、候选仍有相同墙端和开口时，用 `plan-coordinate-view.py` 查看候选原像素，按[固定底图编辑](locked-plan-edit.md)在 JSON 写覆盖改区的原图和候选同名点。在该版条目用 `geometry` 引入这个文件，传它对应的单张候选。候选里有对象、贴回后被切断或缺失时，先查它是否偏出引导框或穿过保留项，按实际情况用同批备选或只改该区域。仍有硬缺项的版本留在工作区，只登记通过复核的版本。版间同口径说明人数、使用差异和待尺项。

已有完整画幅的合成底图，且只需清除重复门弧、残线或回贴原门时，在各版条目把 `candidate` 写为上一轮的 `composition.png`，将[局部修补 JSON](locked-plan-edit.md#只清门洞残线)填入 `repair` 并沿用该版回执。用同一条贴回命令和新的输出目录处理有缺项的各版。保留区内原有线条由贴回恢复。家具本体跨过保留区时，先判断是否有真实可用的完整落位，可用同批备选或局部生图重排。查看修补后的实际图面再登记。

某版只剩开口未通过时，先看返回的 `detailsPng` 和 `localPatch.referenceImage`。有另一张候选时仍看关键空间是否齐全，优先修真正能交付的一张。先用首轮允许的范围局部修正门扇、门槛和地面。

### 修复被分隔截断的床

同批有完整可达的床位时优先用它。整图其它内容可用、仅床体跨保留分隔或被贴回裁断时，可用当前 `composition.png` 和原回执做局部修补。先用返回的局部图或原像素坐标图找齐床头、床尾及残影。对原本要保留的灰区用 `restore` 恢复原图，对允许装饰的地面以 `clear` 去掉残影，沿用相同材质的空白处取样。最后用 `bed` 从已核的占位画清床头和完整床体。

```json
{"repairs":[{"type":"clear","rect":[200,140,270,250],"backgroundFrom":[300,150]},{"type":"bed","rect":[205,260,277,377],"head":"top"}]}
```

尺寸与坐标取自本题原图。 `head` 用 `top/bottom/left/right` 表示图面朝向。把修补 JSON 填入本版的 `repair`，用原图和原版回执重验。工具校验床体矩形位于准许编辑的区内。复核实际图时还要看到门扇、床边与连通路线，旧床残影、掉字和误贴材质也需处理。床体采用简式平面图元，适合表达布局。需要统一表现的彩平可将局部图用于一次生图并复核。

### 多版引导

底图带有大片页眉、页脚或留白时，把要送生图的整户裁切写入共用复核的 `crop: [左,上,宽,高]`。裁切覆盖改区和整个需要保留的户型，所有坐标仍取用户原图。用 `annotate-plan.py` 按这份复核输出引导及回执，合成时传用户原图及原回执。只换家具且沿用原开口时，复核可用共用计划点，省去开口字段。

以[固定底图编辑](locked-plan-edit.md)的复核 JSON 为基础。共用 `edits` 放全案都允许布置的区，`locks`、`darkDoorLocks` 和 `planPoints` 的 `preserve` 放每版都固定的内容。共用 `unconfirmedAreas` 随每版引导标成紫线，并作为原图保护多边形。版间确知可改的分隔写入 `optionalSeparators`，每项含 `id`、原图坐标的 `crossing`（`state: "proposed"`，含精确 `clearRect`）及保留时使用的 `locks`、`darkDoorLocks` 或 `preservePoints`。共用编辑范围里的固定墙端仍由共用锁保护。

把各版放在 `{"variants":[{"id":"A","openSeparators":[],"planPoints":[]},{"id":"B","openSeparators":["客厅阳台分隔"],"planPoints":[]}]}`。每版填写本案要开的分隔和要检查的实际落位。选中的分隔按清除矩形加入改区并生成开口检查，其余分隔带入保留项。沿用相同布置引导时，可只使用共用 JSON。

```text
python -B -X utf8 "<Skill 路径>/scripts/prepare-plan-variants.py" --original-path "<用户原图>" --review-path ".design-agent/共用复核.json" --variants-path ".design-agent/各版落位.json" --scope-directory ".design-agent/平面首轮范围" --output-directory ".design-agent/多版引导" --colored-plan
```

用 `write_file` 写 JSON，再用 `execute` 运行这一条。先做首版可加 `--variant-id A`，补下一批使用新的输出目录。所有版本直接共用一张引导时省去 `--variants-path`。仅在已确认要保留所有实心扫描区时加 `--protect-filled-regions`。彩平要预演清理已确认可拆的墙线时，保留 `--colored-plan` 并加 `--show-openings-cleared`。用各条目的 `guidePath` 生图，将对应的 `planReceiptPath` 交给贴回命令。预检报家具与保护区相交时，按 `conflictBounds` 看原图实际相交处，优先平移完整占位和操作面。首版通过即可出图，其余版的局部冲突随各版继续处理。

```text
python -B -X utf8 "<Skill 路径>/scripts/annotate-plan.py" --input-path "<原图>" --geometry-path ".design-agent/共用复核.json" --variant-path ".design-agent/B.json" --output-path ".design-agent/B-引导.png" --check-plan-points --colored-plan --plan-receipt-path ".design-agent/B-回执.json"
```

先用上述命令即可生成房间、家具和拟设开口引导。对希望在引导先擦去的分隔，确认 `clearRect` 完全落在开口采样带内，覆盖要擦的线，采样两端在矩形外的地面上，再加 `--show-openings-cleared --keep-uncleared-openings`。每次 `generate_image` 直接传该版 `guidePath`，贴回原图时传对应 `planReceiptPath`。若引导保留了蓝带，按原定开口在成图逐一检查。分版引导共用相同的原图与硬约束，家具和开口按各版单独验收。

每版首次通过预检时，`--scope-directory` 保存该版最初的可改区和保护项。续改沿用该目录及版号，临时引导每次输出到新目录。最后贴回并登记时，当前回执会自动校对首轮范围。旧任务续改时可用 `--initial-guide-directory "<首轮引导目录>"`，贴回时传同一首轮目录；用单版命令则传该版 `--initial-plan-receipt-path`。候选把既有门扇画到别处时，在原回执范围内修正错线。原画面保留区域因贴回而仍呈原图颜色时，可在图上说明保留现状。
