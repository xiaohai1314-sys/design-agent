# 住宅房间布置

按本题原尺寸和实际使用者落位。以下尺寸是选型示例，单位 mm。先用已有标注定比例，再按外框画家具，替门扇、柜门和使用者留出动作空间。

| 空间 | 怎样布置和画 | 在图上试一次 |
| --- | --- | --- |
| 玄关接餐区 | 门边有短实墙且只需收纳时，沿墙画浅柜。进门直望厨房门或私区且要求遮挡时，比较入口内侧的短屏与邻墙柜组合，屏端留转入客餐区的开口。浅翻斗鞋柜可约 180 深，带坐面的换鞋凳约 350 深，按实际型号取值。柜、屏与餐桌椅分别画实际俯视占地，用细线区别于承重墙。 | 画门扇扫过区，沿入户视线检查是否挡住目标，再绕屏转身、换鞋、拉餐椅。若上方是通阳台的开口，沿墙柜止于门垛。用户要通透时沿侧墙整合鞋柜即可。 |
| 卧室、照护房、书房 | 用枕头指向连续床头墙，床头板贴墙，双人床留实际上下床侧。床垫如 1200×2000 或 1500×2000，另计床框；优先题定尺寸。衣柜另择可取衣的墙段。书桌有坐姿朝向，工位数随人数。桌靠能使用的墙面或窗侧，椅背退出后与床沿分离。 | 从门走到床侧，再打开衣柜、拉出椅子；老人房另走夜间如厕路线。床头不能靠在可开启的柜门、窗洞或半空。窗前桌椅四脚均落室内地面。 |
| 卫生间 | 先认排水、湿墙和门的来向，再摆便器、台盆、按需设置的淋浴。按洁具完整外廓画出台面深度、盆前站位、厕前起身及淋浴入口。受限时比较移门或向外开启的条件；先用帘或淋浴隔断试排，台盆与坐便器同处可达的干侧。 | 从门外依次试开门、洗手、坐下、进淋浴。门弧扫到盆、隔断封死或为凑三件把台盆缩成小点，须重排。按实际入口区分套卫和公卫；干区外移后只保留所需洗手位。适老题核助行空间。 |
| 厨房 | 沿可接驳墙用平行的墙边线与台面前沿画出柜深，转角接齐，柜端封边；水槽和灶嵌在台面内，过门处整段断开。常规地柜可用约 600 深试排；冰箱按实际机身、铰侧、抽屉和开门投影另算。宽厨房比较转角或双排，岛台须留操作和绕行位置。 | 从餐区进厨房再到家政间，门扇打开、拉出餐椅后都能通行；窄处先缩短半岛或改沿墙台。试开冰箱和洗碗机。 |
| 阳台、飘窗 | 家务阳台在接驳端集中洗衣、储藏，另一段留取衣和晾晒。休闲阳台以实际进深选座位。凸窗保留窗台及折角，窗下地坪与窗台分开画。 | 抱衣篮走进原门、开机门、取衣。原图只有窗洞时不假设能穿过；标出待核的可达条件。 |
| 客餐厅、储物 | 先以实际人数组合座位，再找对面的有效电视墙。常规沙发和电视柜分别贴可用墙；离墙布置需能交代后方用途和通行宽度。餐椅拉出后仍须能去厨房。储物间沿墙画有深度的架和取物面。 | 从玄关走到卧室、阳台和餐位；从沙发看电视。找不到目的地的窄夹道并回可用空间。 |

需要独立有窗房时，隔墙终点选窗间墙垛，每间核原窗和入口。公区及设备腔保留原界。原结构尺寸无法同时满足要求时，说明发生冲突的位置和取舍。
