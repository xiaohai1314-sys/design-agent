# 家装平面

先确认是住宅室内布局，再看整组附件真实类型和目标。出现原生 CAD（DWG、DXF 等）或三维模型（SKP、RVT、3DM、OBJ、FBX、GLB 等），交给对应流程；要求交付或编辑此类文件时同样分流。CAD 导出的 PDF、截图按二维材料处理。含图文档取户型所在页，保留原比例和尺寸。住宅内书房属于家装，办公楼、商铺、酒店客房等按项目用途分流。读原题及修改意见，区分硬性要求与参考。按要求出图，默认一张。仅审图见[底图审改](references/existing-plan.md)。

参考文档中的脚本用任务环境提供的 `python` 执行。脚本可用当前任务目录下的相对路径或工具返回的绝对路径。

## 在原图上定尺度和开口

按原朝向、横纵已知尺寸定比例。从入户沿外墙逐段追到原门另一端，核每个凹角、退台、飘窗内外沿和阳台分界，再对内部固定墙端和开间。保留管井、前室及室外边界。仅按题意调整已明确可拆的隔墙。合户在可拆段留贯通口，两边能直接走通，保留承重墙与公区。各稿同底图；分析图在已核布局上叠加说明。

常规首轮以干净原图为第一张参考。固定底图编辑、跨层定梯和按尺寸出图按各自流程指定的底图生图，原图用于合成与复核。底图缺房名时，由智能体根据题干、原门洞、厨卫设备和管井拟定房间用途；不确定处保留原构造，注明假设并继续布局。除非用户明确要求亲自圈选，不调用 `ask_image_edit`，也不以文字要求用户标注。确需定位时自行制作同画幅标注副本，见[最小引导](references/image-generation.md#最小引导)，仅能安全隔离且允许改动的门轨用[去门轨副本](references/image-generation.md#去门轨引导副本)。纯文字题按[单房净尺寸](references/rectangle-layout.md)。独立尺寸图、跨层楼梯、固定底图分别见[尺寸图](references/dimension-plan.md)、[跨层复核](references/stair-pair.md)、[固定底图编辑](references/locked-plan-edit.md)。

## 先留出人能走和使用的位置

- 布置前，逐门从来路穿过整段净开口，走到门后第一处能站人的空地。把门外接近和转弯处、门扇扫过区、门内落脚处都留空。相邻门连着试走，包括储物间、衣帽间与阳台。一个洞口画一次原门型。柜体、电视柜和台面只画在扣除这些空地后的连续实墙段上，端头止在门垛旁；无合适墙就换墙、缩短或取消该件。私室有完整分界，独立卧室和公卫从公共区可达，主卫从套内可达。
- 用[住宅布置](references/residential.md)按真实外廓落家具。在最挤处沿同一截线，用两固定面之间的净距减去家具占深和开启占位，核剩余通行宽度；有底图刻度才报数。优先核床侧到柜门、电视柜端到墙、退椅后到入户门。窄处先减柜深、换墙或取消副椅，不缩画床、桌椅或门。玄关兼餐区时，按用餐人数靠近厨房一侧布置并让开入户路径。走道余地按相邻功能利用，原设备腔和检修口保留。
- 卫生间先在原湿墙侧试排一座便器、一台盆及题需淋浴，画出各自站位与连续入口。需干湿分离时先在室内隔开淋浴，台盆仍可在内；仅明确要求或室内确实放不下、且室外站位不占门路时外置。按题区分多盆、浴缸、适老叠用等需要。紧凑公卫优先可用，套卫另从主卧床侧走到洁具。

## 生图

布局落定后，从本 Skill 目录运行 `python -B scripts/read-rewrite-sections.py "<当前挂载的 image-prompt-rewrite 目录>"`，只用返回的住宅改写段落组装 `generate_image.query`，跳过外部交互流程。无房名时把模板中的“根据上传户型图中标注房间名”替换为本轮拟定的房间位置和用途。若脚本或模板不可用，直接用已定布局和下述画法出图。纯文字题沿用题给尺寸和落位。

核对原尺寸、入口、套间归属、逐卫洁具数量、设备落位和方案差异均已写入改写结果，再把结果作为 `generate_image` 的非空 `query`，另传独立 `image_name` 和参考 `image_urls`。[调用与异常](references/image-generation.md)。把临门家具写成具体落位，例如「从厨房穿门到洗衣机；地柜止于灶旁门垛，储物架转到侧墙」。多方案先发齐独立方案，各稿用同一底图。分析附图用已通过复核的布置图生成。

默认白底黑线正投影，实墙用粗线连续填实，原红色剪力墙原位等厚转黑。门窗、家具和洁具用细线俯视图例，单扇平开门画一条门扇线及以铰点为圆心的开启弧。原图需延续彩平或用户明确要求时，沿用相同图例着色。

## 复核与交付

打开每张候选，与底图同向等比并排，逐项比对保留的尺寸数字、阳台分界及各墙门窗。放大每间卫浴，按落位点数坐便器、台盆和淋浴，外置盆计入所属卫生间。沿图上门洞从公共区走到独立房间，从主卧走到套内衣帽间和主卫，核门扇开启、落脚净空及柜体是否截断通路。检查抖线、重影和遗漏。保留最佳候选，发现错漏时局部返修一次，再复核相邻空间和同一条通路。选最符合题意的一张；仍有缺陷时标为「复核稿」并点明位置。

逐方案打开实际交付的完整图片，用 `deliver` 登记并核对回执。无可读候选时按[返图兜底](references/image-generation.md#调用回执与失败)交付阶段方案；登记失败时提供已核对的成果路径。
