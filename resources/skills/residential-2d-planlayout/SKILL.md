# 住宅平面（二维材料）

把户型图、截图或扫描件转成可评审的平面方案。先确认比例和结构，再谈排布。

## 能力边界

- 只处理**家装住宅**。办公、商铺、酒店客房按项目用途分流。
- 只吃二维材料：图片、截图、扫描件、PDF 里的户型页。原生 CAD 交给 `residential-cad-planlayout`。
- 输出是**方案 DXF + 标注图**，不是施工图，也不是效果图。默认一版方案。

## 工作流

### 1. 先看清材料

- 用 `read_file` 打开图片原图，不要只看缩略图。
- PDF 先用 `pdf` 技能取户型所在页，保留原比例。
- 判断材料类型：带尺寸标注的施工图 / 带家具的营销户型图 / 手绘或翻拍照片。三者精度不同，方案的可信度也不同。

### 2. 定比例（这一步不能跳）

二维材料没有真实坐标，必须先把像素换算成毫米：

1. 先找图上**已有标注**的尺寸（开间、进深、门宽）。
2. 没有标注时，找门洞按 900mm、外墙按 200mm 这类常识值反推，并在交付说明里写明这是估算。
3. 完全没有参照物时，只做相对布局，**不要编造绝对尺寸**，并在说明里明确写「比例未知，尺寸为相对关系」。

### 3. 描述方案

用和 CAD 流程同一套 `layout.json`（单位 mm）：

```json
{
  "unit": "mm",
  "rooms":     [{"name": "主卧", "x": 0, "y": 0, "w": 3800, "h": 3300}],
  "walls":     [{"x1": 0, "y1": 0, "x2": 8000, "y2": 0, "thickness": 200}],
  "openings":  [{"x": 3000, "y": 0, "width": 900, "orient": "h", "kind": "door"}],
  "furniture": [{"x": 1000, "y": 500, "w": 1800, "h": 2000, "label": "双人床"}]
}
```

### 4. 校验并出图

校验与出 DXF 复用住宅 CAD 技能的脚本（兄弟目录）：

```bash
python <技能目录>/../residential-cad-planlayout/scripts/plan_dxf.py check layout.json
python <技能目录>/../residential-cad-planlayout/scripts/plan_dxf.py build layout.json 平面方案.dxf
```

校验规则同 CAD 流程：墙段长度、门洞宽度、房间尺寸、洞口是否落在墙上。

### 5. 在原图上标注，供用户核对

```bash
python <技能目录>/scripts/annotate_plan.py spec.json
```

`spec.json` 用**图片像素**坐标（不是毫米）：

```json
{
  "image":  "户型.png",
  "output": "户型-标注.png",
  "rooms":  [{"x1": 100, "y1": 100, "x2": 900, "y2": 800, "text": "主卧 3800×3300"}],
  "dims":   [{"x1": 100, "y1": 820, "x2": 900, "y2": 820, "text": "3800"}],
  "labels": [{"x": 500, "y": 60, "text": "方案 A", "size": 34}]
}
```

标注完用 `read_file` 打开生成图自查一遍：文字是否压住图形、色块是否框错房间。这一步是交付前最后一道关。

### 6. 交付

- 方案 DXF 路径
- 标注图路径
- 文字说明：比例是怎么定的、保留了哪些结构、每个房间面积、主要家具尺寸
- 待确认项：哪些尺寸是估的、哪些位置需要现场核实

## 尺寸基准

| 项目 | 下限 |
|---|---|
| 入户门洞 | 900mm |
| 卧室门洞 | 800mm |
| 卫生间 / 厨房门洞 | 700mm |
| 主通道净宽 | 900mm |
| 次通道净宽 | 700mm |
| 床侧通行 | 500mm |
| 衣柜前通行 | 600mm |
| 餐桌边缘到墙 | 800mm |

## 注意

- **不要凭图编尺寸**。看不清就问用户，或明确标注为估算。
- 承重墙、管井不擅自改动；二维材料上分不清承重与否时，一律按不可拆处理并在说明里注明。
- 不做效果图、彩平图；需要时转 `image-prompt-rewrite` + `generate_image`。
- 翻拍照片常有透视变形，先说明这一点再给方案。
