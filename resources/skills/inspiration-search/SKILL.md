# 灵感与素材检索

`search_inspiration` 返回的是**检索结果**，不是**精选方案**。本技能只管一件事：把工具真实返回的字段，如实、不夸大地说给用户听。

## 先认返回形态

**先看返回的开头**，它决定后面怎么走：

- 以 `{` 开头 → JSON，按下面的字段表读。
- 「本地灵感库尚未就绪…」「本地灵感库目录尚未配置…」→ 库没配好。按原文告诉用户去「设置 → 本地规范知识库」确认目录或用「重建索引」生成，**不要**把这句当成"没找到相关素材"。
- 「…中未检索到与…直接匹配的灵感/素材」→ 检索确实没命中。给改写建议（补风格 / 建筑类型 / 材质关键词），**不要**凭常识补几个案例顶上。

## 返回字段

| 字段 | 含义 | 能怎么用 |
|---|---|---|
| `hits` | 本地命中，**最多 8 条**，按相关度排序 | 逐条列给用户 |
| `localTotal` | 本地相关条目总数（可能大于 8） | 说「共 N 条相关，列出前 8 条」 |
| `indexTotal` | 索引总条数 | 只在解释库有多大时用 |
| `vectorUsed` | 本次是否用上语义向量 | `false` 时不能说"语义匹配" |
| `vectorNote` | 退化成纯关键词的原因 | `false` 时一并说明 |
| `webFallback` | 本地不足 3 条时的联网补充，含 `provider` | **单独标出**，不能并进本地结果 |
| `hits[].filePath` | 本地文件路径 | 有才能说"已在本机"，可用 `read_file` 打开 |
| `hits[].sourceUrl` | 来源链接 | 有才给，没有不许编 |
| `hits[].prompt` | 库里的生图提示词（截断 600 字） | 可展示或直接拿去生图，注明是库里的配方 |

`hits` 里**没有**相关度分数，也没有 id。不要自己编「匹配度 92%」这类数字。

## 措辞纪律

**1. 说「列出前 N 条」，不说「精选」。**
本地最多返回 8 条，是按关键词 / 向量分数排序后截断的，没有经过任何二次筛选。

- ✅ 本地库共 12 条相关结果，按相关度列出前 8 条：
- ❌ 已从海量素材中精选出以下高匹配案例：

**2. 纯关键词检索不许包装成语义匹配。**
`vectorUsed: false` 时本次只做了字面匹配（原因在 `vectorNote`，通常是本地向量模型没下载）。可以如实说「本次为关键词匹配」，也可以不提匹配方式，但不能说「按语义找到」「理解你的意图后推荐」。

**3. 联网结果和本地结果必须分开说。**
出现 `webFallback` 说明本地命中不足（少于 3 条）才去联网，要把 `provider` 一并说明。联网结果来自公开网络，不是用户的素材库：

- ✅ 本地库只有 2 条相关；另从公开网络（Tavily）补充了以下资料：
- ❌ 已为你整理出以下素材：

**4. 没返回的东西不许补。**
不凭标题联想图片内容，不编「这套适合北欧风」这类推荐理由，不补写没返回的年份、面积、设计单位。要评价某张图，先 `read_file` 打开看过再说。

**5. 不暴露内部字段名。**
说「本地库 12 条相关」而不是「`localTotal=12`」，说「本次是关键词匹配」而不是「`vectorUsed=false`」。

**6. 以图搜图要确认真的生效。**
传了 `image_path` 但 `vectorUsed: false`，说明图像向量没用上（模型未下载，或索引里没有图像向量），要告诉用户这次退化成文字检索了，别让用户以为以图搜图成功了。

## 输出模板

有命中时：

```text
本地灵感库共 {localTotal} 条相关结果，按相关度列出前 {hits.length} 条：

1. {title}（{style} / {buildingType}）
   来源：{source}（有 sourceUrl 才附链接）
   本地文件：{filePath}

（出现 webFallback 时追加）
本地命中不足，另从公开网络（{provider}）补充了 {n} 条资料，这些不是本地素材：
```

一条都没有时：

```text
本地灵感库（共 {indexTotal} 条索引）里没有和「{query}」直接匹配的结果。
可以补充风格、建筑类型或材质关键词再试，例如……
```

## 边界

- 本技能只管**怎么讲检索结果**。要基于结果继续做效果图、方案或建模，转对应技能。
- 用户问的是规范条文而不是素材时，用 `retrieve_regulation_chunks`，不要拿本工具凑数。
- 用户只要一两张参考图时，给前几条就够，不要把 8 条全铺开。
