# 家装平面布局设计提示词生成

## 整体流程

```
用户上传户型图 + 文字描述
       ↓
Step 0: 判断户型图是否有功能标注
       ↓（无标注时）调用 ask_image_edit() 提醒标注 → 用户提交标注后的图
       ↓（有标注 / 用户完成标注后）
Step 1: 提取用户特殊要求
       ↓
Step 2: 确认出图风格（默认白底黑线纯线稿）
       ↓
Step 3: 拼装最终提示词
```

## Step 0：判断户型图是否有功能标注

识别用户上传的户型图中是否存在**房间功能文字标注**（如"客厅""卧室""餐厅""厨房""卫生间""书房"等标明各区域用途的文字）。

### 判断规则

| 情况               | 处理方式                                                                 |
| ------------------ | ------------------------------------------------------------------------ |
| 图中已有功能标注   | 直接进入 Step 1，以该图为底图                                            |
| 图中无任何功能标注 | 调用 `ask_image_edit()` 工具，弹出轻编辑框，提示用户在图上补充标注后提交 |

### 无标注时的 ask_image_edit() 调用说明

`ask_image_edit` 是按需发现的本地工具，新会话默认不在工具列表里。若当前没有这个工具，先调用 `tool_search({"query":"select:ask_image_edit"})` 取参数契约，再按契约调用；不需要先调 `mcp_tools`。取到后，本会话后续都可直接调用。调用时 `hint` 写给用户看的标注要求，`image_path` 填需要标注的那张图的本地路径；一次只调用本工具，不与其他工具并列。用户确认后，用返回的新图替换原图继续当前步骤；用户取消时本轮会直接结束。

当判断户型图**缺少房间功能文字标注**时，必须在进行任何后续步骤前调用 `ask_image_edit()`，弹出轻编辑框，提醒内容示例：

> 请在图上手动标注各区域的功能(如客厅、卧室)，以便生成更准确的布局方案。

用户在编辑框中完成标注并点击提交后，**以提交的新图作为底图**，再进入 Step 1 开始处理。

### 判断边界

- 仅有尺寸数字（如"3600""2800"）但无功能文字，视为**无标注**
- 仅有指北针、比例尺等辅助符号但无功能文字，视为**无标注**
- 功能文字标注不完整（如只标注了部分房间）：仍视为**有标注**，继续执行，不调用 ask_image_edit()

## Step 1：提取用户特殊要求

从用户文字描述中提取明确的布局特殊要求，例如：

- 需要书房 / 儿童房
- 主卧要带衣帽间
- 厨房要开放式
- 餐厅与客厅需连通
- 阳台要做生活阳台等
  若用户无特殊要求，此项在 Step 3 中省略不写。
  **严禁描述用户query中没有的内容**

## Step 2：确认出图风格

| 情况         | 出图风格                       |
| ------------ | ------------------------------ |
| 用户未指定   | 白底黑线纯线稿（默认）         |
| 用户指定风格 | 使用用户指定的描述（如中古风） |

## Step 3：拼装最终提示词

### 模板骨架

```
根据上传户型图中标注房间名生成有家具布置的平面图，在原始户型结构的基础上，完善全屋的功能分区与软装陈设。根据原有墙体布局进行合适的空间布局设计，[用户特殊要求]，呈现出高质量平面布局设计的[出图风格]平面，保持户型承重墙结构不变，比例准确，墙体粗线，其他细线；文字仅标注空间类型。
```

### 各占位符填写规则

| 占位符           | 填写内容                                            |
| ---------------- | --------------------------------------------------- |
| `[用户特殊要求]` | Step 1 提取的特殊要求；若无则删除此占位符及前后逗号 |
| `[出图风格]`     | Step 2 确认的风格，默认为"白底黑线纯线稿"           |

### 拼装示例

**有特殊要求、默认风格：**

> 根据上传户型图中标注房间名生成有家具布置的平面图，在原始户型结构的基础上，完善全屋的功能分区与软装陈设。根据原有墙体布局进行合适的空间布局设计，主卧需带衣帽间区域，呈现出高质量平面布局设计的白底黑线纯线稿平面，保持户型承重墙结构不变，比例准确，墙体粗线，其他细线；文字仅标注空间类型。

**无特殊要求、默认风格：**

> 根据上传户型图中标注房间名生成有家具布置的平面图，在原始户型结构的基础上，完善全屋的功能分区与软装陈设。根据原有墙体布局进行合适的空间布局设计，呈现出高质量平面布局设计的白底黑线纯线稿平面，保持户型承重墙结构不变，比例准确，墙体粗线，其他细线；文字仅标注空间类型。

## 输出规范

1. 仅输出一段完整提示词，不分段、不加标题
2. 全中文输出，专有名词可保留英文
3. 不写废话，不添加引导语
