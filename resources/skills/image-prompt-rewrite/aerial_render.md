# 鸟瞰渲染（Aerial Render）

## 最高优先级约束：视角锁定

用户上传的模型截图代表了其设计意图中的观察视角。**生成结果必须与原图保持完全相同的视角**

**禁止行为**：不得因"更好看"、"更像航拍"、"更标准"等理由擅自抬高相机、切换为正鸟瞰、或调整镜头方向。  
**允许例外**：仅当用户明确表达"换个角度"、"调整视角"、"俯视角"含义时，才可修改视角。
每次生成的 prompt **开头必须**包含以下视角锁定语句（不可省略、不可移至末尾）：

> 「请以完全相同的相机视角、俯仰角度、镜头高度和朝向生成渲染结果，视角不得有任何偏差。」

## 整体流程

```
用户上传鸟瞰模型图（必须）+ 可选风格参考图 + 文字描述
        ↓
Step 1：判断任务模式（单图 / 双图）
        ↓
Step 2：识别场地类型 + 融合用户需求 → 生成鸟瞰专用 Prompt
        ↓
Step 3：调用图像生成工具，展示结果并引导迭代
```

## Step 1：判断任务模式

| 图片数量                                    | 任务模式                                     |
| ------------------------------------------- | -------------------------------------------- |
| **1 张图**（鸟瞰白模/模型截图/鸟瞰线稿）    | 单图模式：白模 → 写实鸟瞰效果图              |
| **2 张图**（图1 鸟瞰白模 + 图2 风格参考图） | 双图模式：白模 + 风格参考 → 风格迁移鸟瞰渲染 |

> **如何区分鸟瞰白模与普通平面图**：
>
> - 鸟瞰白模：有透视感的俯视立体模型截图，可见建筑体块、地形高差、道路层次（通常来自 SketchUp / Rhino / Lumion 的模型视图截图）
> - 普通平面图：纯二维正交俯视线图，无立体感，无透视（CAD 图纸、总平面示意图）

## Step 2：生成 Prompt

### 融合规则

1. 以下方对应模板为基础框架，**不删除任何质量控制语句**
2. 根据用户描述，将场地特征、氛围要求、时间光线等融入 `[...]` 占位符
3. 用户未指定光线时间时，默认「午后3点斜射阳光」
4. 用户未指定风格时，默认「写实航拍摄影质感」
5. 最终 prompt 使用**中文**输出，可保留 8k、aerial photography 等英文质感词
6. **【场景完整性扩展规则】** 当输入图仅包含中间核心设计区域（判断依据：图片四周存在大面积空白/灰色底板/单色背景，或设计内容仅占画面中央一小部分），应主动在 prompt 中加入四周配景扩展指令，使最终输出成为一张完整的照片级鸟瞰效果图，而非"孤岛式"设计图。扩展原则：
   - **信息锁定**：根据用户上传的内容，其中包含的所有几何体量、布局与视角严格不变
   - **四周自然延伸**：根据场地类型，向外扩展符合逻辑的城市环境配景（周边道路、街区建筑、城市绿化、远景天际线等）
   - **边界自然过渡**：核心设计区与周边扩展配景之间无明显边界感，融合自然
   - **去除人工底板**：不得保留原图中的灰色/白色/单色底板，全部替换为真实城市环境
7. **【效果图定位与轻度美化约束】** 必须遵守以下美化原则：
   - **建筑物呈现新建状态**：立面洁净、材质崭新，无风化、污渍、剥落、锈迹等老旧痕迹
   - **景观植被理想化**：草坪平整翠绿、植物修剪有序、铺装整洁无破损
   - **禁止过度写实的陈旧感**：不得出现破败建筑、荒废场地、枯死植被等影响设计展示的负面元素
   - **轻度理想化处理**：整体画面略偏向设计竞赛效果图的精致感，而非真实竣工多年后的状态
   - **设计细节优先**：建筑立面分格、材质肌理、景观铺装图案等设计要素应清晰可辨，不被过度真实的环境噪点掩盖

### 场地类型识别（辅助 prompt 细化）

根据图片内容或用户描述，识别以下场地类型，并在 prompt 中补充对应的配景细化语：
| 场地类型 | 识别依据 | 配景细化补充 |
|----------|----------|-------------|
| **城市公园 / 景观广场** | 大量绿地、水体、园路、景观构筑物 | 丰富的植物群落、水面倒影、游人点缀、铺装肌理 |
| **城市规划 / 设计地块** | 路网结构、地块划分、多栋建筑群 | 街道绿化、城市肌理、车流、远景城市天际线 |
| **园区 / 校园 / 产业园** | 规则建筑群 + 内部景观 | 内庭院绿化、连廊、停车场、功能区分界 |
| **滨水 / 海岸** | 明显水体边界 | 水面质感、船只、堤岸植被、水光反射 |
| **单体建筑鸟瞰** | 主体为单栋或少量建筑 | 建筑周边环境、入口广场、停车区 |

### Prompt 模板库

#### 单图模式：白模 → 写实鸟瞰效果图

```
请以完全相同的相机视角、俯仰角度、镜头高度和朝向生成渲染结果，视角不得有任何偏差。
基于这张鸟瞰白模截图，生成一张写实航拍质感的城市设计渲染图。严格保持原图中所有几何体量、路网结构、建筑轮廓与空间布局完全不变，不得增删或移动任何建筑与构筑物。
在此基础上：
添加真实的材质质感（建筑立面、铺装地面、屋顶绿化等）
丰富植物配景，乔木、灌木、草地层次分明，符合真实城市绿化生态
[场地类型对应配景细化，见上方表格]
光线：[用户指定 / 默认：午后3点自然光，阳光斜射，形成柔和长影，光影如电影般富有叙事感]
氛围：[用户指定 / 默认：高级、精致、充满生机的城市公共空间氛围]
效果图美化要求：所有建筑呈新建竣工状态，立面洁净崭新，无老旧风化痕迹；景观植被理想化处理，草坪平整、植物修剪有序；整体风格偏向设计竞赛效果图的精致感，设计细节（立面分格、铺装肌理、景观图案）清晰可辨。
画质：8k 超清分辨率，照片级真实感，无人机航拍镜头质感，aerial photography。
出图宽高比以原图为准。
```

**若检测到场景不完整 / 存在空白底板时，追加以下扩展指令：**

```
原图中央设计区域保持完全不变；将原图四周的空白/单色底板替换为真实的城市环境配景：[根据场地类型填入，如"周边街道、城市建筑群与行道树"/"邻近社区绿地与城市道路"/"远景城市天际线与街区肌理"]，使整体画面呈现为一张完整的无人机航拍照片，核心设计区与周边环境之间自然融合、无明显边界感。
```

#### 双图模式：白模 + 风格参考 → 风格迁移鸟瞰渲染

> **多图角色识别**：优先遵循 SKILL.md 多图角色识别结果；用户无声明时默认图1为鸟瞰底图、图2为风格参考图；声明与默认相反时必须在提示词中交换图号。

```
请以完全相同的相机视角、俯仰角度、镜头高度和朝向生成渲染结果，视角不得有任何偏差。
使图2的渲染风格与光影氛围对图1进行高质量写实鸟瞰渲染。保留图1的所有几何体量、路网结构与空间布局完全不变，不得增删或移动任何元素。
迁移图2的以下视觉要素：
色彩基调与饱和度
植物配景的茂密程度与色相层次
光照时间与阴影方向
镜头质感（景深、色温、曝光风格）
整体城市氛围与精致程度
[若用户有额外要求，在此追加：如"增加水面"、"傍晚光线"等]
生成一张高级、精致、美丽的超清城市设计渲染图，aerial photography，8k。所有建筑呈新建竣工状态，立面洁净崭新；景观植被理想化，整体偏向设计竞赛效果图的精致感，设计细节清晰可辨。
出图宽高比以图1为准。
```
