# 平面填彩（Colorplan）提示词生成

## 整体流程

```
用户上传图片 + 描述需求
       ↓
Step 1: 判断领域和任务类型
       ↓
Step 2: 融合用户query与模板提示词，生成最终prompt
```

## Step 1：判断领域与任务类型

根据用户上传的图片内容和文字描述，综合判断：

### 1.1 领域判断

从以下三个领域中选择一个：
| 领域 | 判断依据 |
|------|----------|
| **室内（家装/工装）** | 图片为室内户型图、平面布局图，包含家具、房间分隔、卫生间厨房等元素；或用户提到"室内"、"户型"、"家装"、"工装"、"房间"等关键词 |
| **建筑** | 图片为建筑总平面图，包含建筑体块、屋顶轮廓、道路、场地等元素；或用户提到"建筑"、"总平"、"总图"、"规划"等关键词 |
| **景观** | 图片为景观总平面图，包含植物群落、硬质铺装、水景、园路等元素；或用户提到"景观"、"园林"、"绿化"、"植物"等关键词 |
如果无法确定，默认为 **建筑** 领域。

### 1.2 任务类型判断

根据用户上传图片数量和需求描述判断任务类型：
| 条件 | 任务类型 |
|------|----------|
| 上传 **1张图** + 无特殊风格要求 | 建筑景观领域默认彩色平面图生成，室内领域默认3D平面图生成 |
| 上传 **1张图** + 要求2D平面图（仅室内领域） | 彩色平面图生成 |
| 上传 **1张图** + 要求写实/3D渲染平面图（仅室内领域） | 3D平面图生成 |
| 上传 **1张图** + 要求写实/照片风格（建筑或景观领域） | 写实总平面图 |
| 上传 **2张图**（图1为待处理线稿，图2为参考风格图） | 参考图填色 |

## Step 2：融合提示词

根据Step 1确定的领域和任务类型，从下方提示词模板库中选取对应模板，然后将用户的个性化需求（如风格偏好、颜色要求等）融入其中，形成最终的彩图提示词。

### 融合规则

1. 以模板提示词为基础框架
2. 将用户query中的个性化要求（风格、颜色、氛围等）融入模板中
3. 如果用户指定了具体风格（如"中式风格"、"淡雅"、"现代"等），在模板基础上追加风格描述
4. 最终prompt使用中文输出

### 提示词模板库

#### 室内领域

**彩色平面图生成：**

```
请将此室内平面图转化为一张专业级别的2D彩色平面图。最终效果应如同专业室内设计公司出品，拥有高质量精美质感的2D彩色平面图。
```

**3D平面图生成（默认）：**

```
将这张平面图变成3D渲染风格图片，将家具和地面变成3D渲染风格，让家具在地面上投下柔和的阴影，从而营造出完整的空间立体感与渲染风格。
```

**参考图填色（2张图）：**

```
让图1参考和学习图2中平面家具、地面、阴影等元素的颜色风格，保持图1的画面内容完全不变，以图2的画面风格来呈现效果。使其成为一张生动而立体的彩色图纸。出图结果宽高比以图1为准。
```

#### 建筑领域

**彩色总平面图（默认）：**

```
请将此总平面图转化为一张专业级别的彩色总平面图。在保留原有线条轮廓与细节的基础上，将屋顶设为白色，道路为浅灰色，并点缀浅绿色的树木植物，为整个画面添加柔和的投影，最终效果应如同专业设计公司出品，拥有高质量精美质感的彩色总平面图。
```

**写实总平面图：**

```
将此总平面图转化为写实照片风格。在保留原有线条轮廓与细节的基础上，将屋顶设为白色，道路为浅灰色，并点缀浅绿色的树木植物，为整个画面添加柔和的投影，使其成为一张生动而立体的彩色总平面图。
```

**参考图填色（2张图）：**

```
让图1参考和学习图2中的颜色风格与元素，保持图1的画面内容完全不变，以图2的画面风格来呈现效果。使其成为一张生动而立体的彩色图纸。出图结果宽高比以图1为准。
```

#### 景观领域

**写实总平面图（默认）：**

```
将此总平面图转化为写实照片风格。在保留原有线条轮廓与细节的基础上，道路为浅灰色，真实的硬质铺装纹理，并点缀浅绿色的树木植物，植物分布需呈现自然的群落生态，树冠需独立清晰，具有真实的阴影和层次感，表现出乔木、灌木、地被的垂直群落结构，疏密有致，留出呼吸感，为整个画面添加柔和的投影，使其成为一张生动而立体的彩色总平面图。
```

**参考图填色（2张图）：**

```
让图1参考和学习图2中的颜色风格与元素，保持图1的画面内容完全不变，以图2的画面风格来呈现效果。使其成为一张生动而立体的彩色图纸。出图结果宽高比以图1为准。
```

## 边界情况处理

| 情况                    | 处理方式                                                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 2张图但不确定哪张是底图 | 优先遵循 SKILL.md 多图角色识别结果；用户无声明时默认图1为待处理线稿、图2为参考风格图；声明与默认相反时必须在提示词中交换图号 |

## 输出

仅输出一个最终的提示词即可，不得输出多个
