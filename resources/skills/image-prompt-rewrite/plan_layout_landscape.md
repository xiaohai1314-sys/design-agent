# 景观平面布局设计提示词生成

## 整体流程

```
用户上传场地底图 + 文字描述
       ↓
Step 1: 红线识别
       ↓（无红线）调用 ask_image_edit() 提醒标注 → 用户提交红线标注后的图
       ↓（有红线 / 用户完成红线标注后）
Step 2: 设计标注识别 & 建筑识别（仅判断有无，供 Step 3 用）
       ↓
Step 3: 提示词拼装
```

## Step 1：红线识别

识别用户上传的场地底图中是否存在**设计红线**（红色围合线，实线或虚线，明确圈出本次设计的用地范围）。

| 情况             | 处理方式                                                            |
| ---------------- | ------------------------------------------------------------------- |
| 图中已有设计红线 | 进入 Step 2                                                         |
| 图中无设计红线   | 调用 `ask_image_edit()`，弹出轻编辑框，提示用户在图上补充标注后提交 |

### 无红线时的 ask_image_edit() 调用说明

`ask_image_edit` 是按需发现的本地工具，新会话默认不在工具列表里。若当前没有这个工具，先调用 `tool_search({"query":"select:ask_image_edit"})` 取参数契约，再按契约调用；不需要先调 `mcp_tools`。取到后，本会话后续都可直接调用。调用时 `hint` 写给用户看的标注要求，`image_path` 填需要标注的那张图的本地路径；一次只调用本工具，不与其他工具并列。用户确认后，用返回的新图替换原图继续当前步骤；用户取消时本轮会直接结束。

当判断场地底图**缺少设计红线**时，必须在进行任何后续步骤前调用 `ask_image_edit()`，弹出轻编辑框，提醒内容示例：

> 请在场地图上用红色线条圈出本次景观设计的红线范围，以便严格限定设计区域。

用户在编辑框中完成标注并点击提交后，**以提交的新图作为底图**，再进入 Step 2 开始处理。

**判断边界：**

- 仅有黑色/蓝色等其他颜色的围合边界但无红色线条 → 视为**无红线**
- 仅有道路、建筑、水体等隐含围合，无明确红色线条 → 视为**无红线**
- 红线没有围合，只有一段 → 视为**无红线**
- 仅圈出部分区域 → 仍视为**有红线**，继续执行
- 用户文字中描述了设计范围（如"绿色区域""中央草坪"等），但图中没有红线→ **仍视为无红线，必须调用 `ask_image_edit()`，不得以文字描述替代红线**

## Step 2：设计标注识别 & 建筑识别

**2a. 设计标注识别**

判断底图中是否存在**纯文字形式的设计标注**（功能分区名称、节点名称、区域文字注释等文字内容），记录结果供 Step 3 使用。

> **判断边界：**
>
> - 有中文/英文文字标注（如"入口广场""停车区""中心草坪"等）→ 视为**有标注**
> - 仅有轴线、箭头、尺寸线、网格线、编号圆圈等图形元素，无文字 → 视为**无标注**
> - 图形元素不论多少，不构成"有标注"的判断依据

> 标注内容不作为设计提取来源，不得写入提示词文字，仅决定是否在提示词中加入"按照图中标注进行设计"。

**2b. 建筑识别**

判断底图中是否存在**建筑轮廓**（含已建成建筑、规划建筑、构筑物等以封闭多边形或阴影块表示的建筑体量），记录结果供 Step 3 使用。

> **判断边界：**
>
> - 图中有封闭的建筑轮廓（矩形、多边形块体，通常带有阴影、填充或标注"建筑"）→ 视为**有建筑**
> - 仅有道路、围墙、用地边界等线性元素，无建筑体量 → 视为**无建筑**

## Step 3：提示词拼装

**从用户文字描述中提取以下内容**（仅使用用户明确写出的，不得推断补充）：

| 提取项        | 处理规则                                         |
| ------------- | ------------------------------------------------ |
| 场地类型      | 用户说明则原文使用；未说明则省略                 |
| 设计风格      | 用户说明则原文使用；未说明则默认为“现代风格”     |
| 功能分区/节点 | 用户说明则原文使用；未说明则省略                 |
| 植物配置      | 用户说明则原文使用；未说明则默认为“乔木疏密有致” |
| 铺装要求      | 用户说明则原文使用；未说明则省略                 |
| 水景要求      | 用户说明则原文使用；未说明则省略                 |
| 其他特殊要求  | 用户说明则原文使用；未说明则省略                 |

> 水景不进功能分区节点列举，单独作为水景要求项。
> 各提取项能从用户文字描述中直接得到，严禁补充用户文字描述中没有的内容

**拼装提示词（按条件逐段拼接）：**

| 段落     | 内容                                                                                                                               | 条件                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 固定开头 | `以上传的场地图为底图，严格在红线范围内进行景观设计，正投影俯视角度，红线外设计保持不变。`                                         | 始终插入                                         |
| 建筑保留 | `保持图中所有建筑的位置、轮廓、朝向完全不变。`                                                                                     | Step 2b **有建筑** → 插入；无建筑 → 整句省略     |
| 标注遵从 | `按照图中标注进行设计。`                                                                                                           | Step 2a **有标注** → 插入；无标注 → 整句省略     |
| 用户要求 | 将提取到的各项以句号结尾依次拼入，如`设计风格：法式现代。铺装要求：铺装小径蜿蜒穿插。`                                             | 用户**有**文字说明 → 插入；无任何说明 → 整段省略 |
| 固定结尾 | `出图风格：整体专业白底黑线景观总平风格，细节简洁细腻。禁止在红线外增加设计信息，禁止改变红线位置和角度，最终图纸中不要出现红线。` | 始终插入                                         |

> **禁止将底图中读取到的标注信息写入提示词文字**：图中标注通过图片本身传递给生图工具，不得在提示词中复述。

## 输出规范

1. 仅输出一段完整提示词，不分段、不加标题
2. 全中文输出，专有名词可保留英文
3. 不写废话，不添加引导语
4. 出图风格固定为”整体专业白底黑线景观总平风格”，不得根据用户要求覆盖

## 彩色输出引导

若用户明确要求彩色景观总平（如”彩平图””彩色总平””上色”等表述），**不修改本次生图的出图风格**，仍按黑白线稿生成。在生图完成后，向用户补充说明：

> 景观总平已按标准黑白线稿风格生成。如需彩色版本，可将此图作为底图，告诉我”帮这张图生成彩平图”，我将为您进行彩色渲染。
