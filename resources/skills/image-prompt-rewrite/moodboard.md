# 情绪材料板提示词生成（Moodboard Prompt）

## 整体流程

```
用户输入（图片 + 文字描述，或仅文字描述）
       ↓
Step 1: 分析偏好 — 提取 style_preference / material_preference / color_preference
       ↓
Step 2: 按 7 模块法生成 Banana 提示词
       ↓
输出最终提示词
```

## Step 1：偏好分析

从用户的文字 query 和上传的图片中，综合提取以下三个维度的信息：
| 维度 | 说明 | 示例 |
|------|------|------|
| **style_preference**（风格倾向） | 整体设计风格、美学取向 | 侘寂风、法式轻奢、工业风、孟菲斯波普、自然森系 |
| **material_preference**（材料倾向） | 核心材质关键词 | 微水泥、老木头、大理石、黄铜、长虹玻璃 |
| **color_preference**（色彩倾向） | 主色调和辅助色 | 大地色、墨绿+金色、粉色+绿色 |

### 分析优先级

1. **用户文字描述中的显式信息优先**：如果用户明确说了"侘寂风"、"用大理石和黄铜"，直接采用。
2. **图片分析作为补充**：如果用户上传了参考图片，从图片中识别材质纹理、色调氛围、空间风格，作为补充或验证。
3. **信息不足时主动推断**：如果用户只说了一个模糊方向（如"高级感"），根据常见设计认知合理推断三个维度，并在回复中说明推断依据。

### 边界情况

- **只有图片没有文字**：完全依赖图片分析，从中提取风格、可见材质、主色调。
- **只有文字没有图片**：完全依赖文字信息进行推断。
- **信息非常模糊**（如"帮我做个好看的情绪板"）：主动询问用户偏好方向，或给出 2-3 个风格建议供选择。

## Step 2：7 模块法生成提示词

确定三个偏好后，严格按以下 7 个模块的顺序拼接提示词。每个模块的内容之间用中文逗号 `，` 连接，最终形成一段连贯的提示词。

### 模块 1：画幅与构图

根据 `style_preference` 动态选择构图方式：
| 风格类型 | 构图选择 |
|----------|----------|
| 严谨/极简/现代/工业 | 几何网格构图（Geometric Grid Layout），模块化排列，秩序感 |
| 自然/有机/森系/侘寂 | 克诺林平铺（Knolling），各元素间保持呼吸感，自然散落布局 |
| 奢华/古典/法式/巴洛克 | 中心层叠构图（Central Layering），大块板材打底，小件物体置于上方，景深丰富 |
| 波普/孟菲斯/混搭 | 艺术拼贴构图，几何元素的趣味组合 |

所有构图都附加通用后缀：`专业室内设计情绪板，专业平铺摄影，正上方90度垂直俯视，无透视变形，干净背景`。

### 模块 2：风格视觉化

将 `style_preference` 翻译为具体的视觉语言描述，涵盖：

- **线条特征**：直线/曲线/混合
- **复杂度**：极简/繁复/适中
- **年代感**：现代/复古/未来
- **情绪氛围**：宁静/活泼/庄重/戏剧性

### 模块 3：核心材料实体

将 `material_preference` 中的每种材料转化为**具有物理体积感的立体形态**。
描述范式：`[表面处理形容词] + [具体形态名词] + [材质名称]`
关键原则：

- 材料不能只是"一块平面的片"，要赋予波浪板、圆柱体、球体、不规则碎块、切片等多样形态。
- 必须描述表面处理（哑光、酸洗面、拉丝、拉槽、磨砂、蚀刻等）。
- 举例仅为参考，根据实际材料灵活创造：
  - 木 → "带锯齿痕的橡木切片"、"圆柱形胡桃木样块"
  - 金属 → "拉丝黄铜圆管"、"蚀刻不锈钢片"
  - 石材 → "表面有涂抹痕迹的微水泥方砖"
  - 玻璃 → "磨砂波浪纹玻璃小样"、"半透明树脂球体"

### 模块 4：软装与色彩载体

将 `color_preference` 赋予布料或特殊材质载体，根据风格决定形态：

- 折叠的绒布（Folded velvet）
- 卷起的亚麻（Rolled linen）
- 流体状的树脂
- 有厚度的烤漆色块
- 哑光色卡、粗织羊毛等

### 模块 5：气氛点缀与建筑碎片

根据 `style_preference` 联想 2-3 个强化风格的"非材料类"小物件，用于丰富画面。参考分类：

- **自然类**：枯枝、苔藓块、鹅卵石、干燥花卉、蕨类叶片、松果
- **建筑类**：石膏角线断块（Cornice fragment）、金属开关面板、复古把手、灯具
- **艺术类**：陶瓷器皿、微缩雕塑
- **工业类**：螺母、电线截面、混凝土碎块
  每次根据当前风格灵活选择，避免重复使用相同的点缀物。

### 模块 6：光影与摄影质感

固定描述（可根据风格微调前缀）：

- 自然风 → `模拟林间斑驳光影，丰富的明暗层次，超写实微距细节，8k分辨率`
- 奢华风 → `柔和的高级灰调光线，细腻的材质光泽，电影级质感，8k超高清`
- 波普风 → `明亮的演播室布光，硬朗的阴影，高光泽度质感，8k分辨率`
- 通用 → `柔和侧向漫射光，深邃的投影，8k分辨率，超高清晰度，虚幻引擎5渲染质感，微距镜头，杂志级商业摄影`

### 模块 7 ：出图比例

用户无特殊指定，默认为1：1， 即在提示词中标明"1:1出图"

## 输出规范

1. **仅输出一段完整的提示词**，7 个模块的内容用逗号连贯拼接，不分段、不加标题。
2. **全中文输出**，专有名词（如 Knolling、Cornice fragment）可保留英文。
3. **不写废话**：不要出现"这展示了"、"我为您生成了"等引导语。
4. **形态具体化**：严禁只说"木头"，必须说"木纹切片"或"木条"等具体形态。
5. **拒绝模板化**：不要每次都用同样的点缀物，根据风格动态调整。

- 提示词：`艺术拼贴构图，几何元素的趣味组合，专业平铺摄影，正上方90度垂直俯视，无透视变形，干净背景。孟菲斯风格，大胆的几何形状，活泼的色彩碰撞，现代且具有戏剧性。一块彩点清晰的粉色水磨石样块，一片绿色的波浪造型长城板（Fluted panel），一个黄铜材质的实心圆柱体。半透明的长虹玻璃小样，高饱和度的橙色烤漆色块，卷起的宝蓝色丝绒布料。点缀着一个球形的磨砂玻璃把手，一片拱形的亚克力片。明亮的演播室布光，硬朗的阴影，高光泽度质感，8k分辨率。1:1出图`
