# 写实精准渲染（realistic_precise_render）

## 整体流程

```
用户上传图片（可选）+ 描述需求
        ↓
Step 1：判断领域 × 任务类型
        ↓
Step 2：选取模板 → 融合用户需求 → 生成最终 prompt
        ↓
Step 3：调用图像生成工具，展示结果并引导迭代
```

## Step 1：判断领域与任务类型

### 1.1 领域判断（三选一）

| 领域                  | 判断依据                                                                   |
| --------------------- | -------------------------------------------------------------------------- |
| **室内（家装/工装）** | 图片为室内空间；或用户提到客厅、卧室、办公室、店铺、家装、工装等           |
| **建筑**              | 图片为建筑外观/体块模型/立面图；或用户提到建筑、外观、立面、外立面、大楼等 |
| **景观**              | 图片为户外空间/园林/；或用户提到景观、园林、花园、庭院、绿化、户外等       |

> 无法判断时默认为**室内**。

### 1.2 任务类型判断

| 图片数量                                            | 任务类型               |
| --------------------------------------------------- | ---------------------- |
| **1 张图**（草图/模型截图/白模/透视线稿）+ 文字描述 | 图生效果图（深化渲染） |
| **2 张图**（图1为底图，图2为风格参考图）            | 参考图风格化           |

## Step 2：生成 Prompt

根据领域 + 任务类型，从下方模板库选取对应模板，将用户的个性化需求（风格、材质、氛围、色调、特定元素等）融入模板，形成最终生图 prompt。

### 融合规则

1. 以模板为基础框架，不删除质量控制语句
2. 将用户描述的风格/颜色/材质/氛围等融入对应占位符 `[...]`
3. 用户未指定风格时，默认填入「现代风格」
4. 最终 prompt 使用**中文**输出，可保留关键英文质感词（8k、V-Ray、Unreal Engine 等）

### 提示词模板库

#### 室内领域

**图生效果图（深化渲染）**

```
基于这张草图/模型截图生成专业级别的渲染效果图。
要求：严格保持原有的空间结构、墙体位置和透视关系不变。在此基础上，添加真实的材质纹理（地板、墙面、家具），生成专业的灯光光影效果，营造空间立体感。
风格：[用户描述的风格]。画质：8k 分辨率，照片级真实感，V-Ray 渲染质感。
```

**参考图风格化（2张图）**

```
让图1参考和学习图2中的色彩风格、材质质感和灯光氛围。保持图1的空间结构和内容完全不变，以图2的视觉风格来呈现效果。
使其成为生动而立体的专业效果图。出图结果宽高比以图1为准。
```

#### 建筑领域

**图生效果图（深化渲染）**

```
基于这张建筑模型/线稿生成专业级别的渲染效果图。
要求：严格保持原有的建筑体块、轮廓和透视关系不变。在此基础上，添加真实的建筑材质，生成专业的日照光影效果，搭配适宜的环境配景（道路、绿化）。
风格：[用户描述的风格]。画质：8k 分辨率，照片级真实感，建筑可视化标准。
```

**参考图风格化（2张图）**

```
让图1参考和学习图2中的色彩风格、材质质感和环境氛围。保持图1的建筑形态和内容完全不变，以图2的视觉风格来呈现效果。
使其成为生动而立体的专业建筑效果图。出图结果宽高比以图1为准。
```

#### 景观领域

**图生效果图（深化渲染）**

```
基于这张景观底图/模型截图生成专业级别的渲染效果图。
要求：严格保持原有的道路路网、场地边界和透视关系不变。在此基础上，添加真实的植物配置（乔木、灌木、地被），生成专业的自然光影效果。
风格：[用户描述的风格]。画质：8k 分辨率，照片级真实感，景观可视化标准。
```

**参考图风格化（2张图）**

```
让图1参考和学习图2中的色彩风格、植物搭配质感和环境氛围。保持图1的场地布局和内容完全不变，以图2的视觉风格来呈现效果。
使其成为生动而立体、光影效果自然的专业景观效果图。出图结果宽高比以图1为准。
```

## 边界情况处理

| 情况                       | 处理方式                                                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 只上传图片，无文字描述     | 根据图片内容判断领域，使用图生效果图模板，风格默认"现代专业风格"                                                       |
| 无法判断领域               | 默认室内（家装工装）                                                                                                   |
| 需求不明确（如"好看一点"） | 使用对应领域默认模板                                                                                                   |
| 2张图但不确定哪张是底图    | 优先遵循 SKILL.md 多图角色识别结果；用户无声明时默认图1为底图、图2为风格参考图；声明与默认相反时必须在提示词中交换图号 |
