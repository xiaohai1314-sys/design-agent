# 实景改造（Real Scene Renovation Skill）

生成将用户上传的真实照片转化为改造效果图的生图 prompt。
核心原则：**严格保持原始空间结构与透视关系，只对用户意图中需要改造的位置进行改造**。

## 整体流程

```
用户上传实景照片（1张或2张）+ 描述改造需求
        ↓
Step 1：判断领域 × 任务类型
        ↓
Step 2：选取模板 → 融合用户需求 → 生成最终 prompt
        ↓
Step 3：告知判断结果，输出最终 prompt
```

## Step 1：判断领域与任务类型

### 1.1 领域判断（三选一）

| 领域                  | 判断依据                                                           |
| --------------------- | ------------------------------------------------------------------ |
| **室内（家装/工装）** | 照片为室内空间；或用户提到客厅、卧室、办公室、餐厅、店铺等         |
| **建筑**              | 照片为建筑外观/立面；或用户提到建筑外观、外立面、大楼等            |
| **景观**              | 照片为景观户外/庭院/绿化；或用户提到景观、花园、庭院、阳台、户外等 |

> 无法判断时默认为**室内**。

### 1.2 任务类型判断

| 图片数量                                     | 用户意图               | 任务类型       |
| -------------------------------------------- | ---------------------- | -------------- |
| **1 张实景照片** + 整体风格需求              | 希望全面翻新为某种风格 | 全场景风格翻新 |
| **1 张实景照片** + 明确指定局部区域          | 只改某个区域，其余不动 | 局部区域改造   |
| **2 张图**（图1为实景底图，图2为风格参考图） | 按照参考图风格改造实景 | 参考图风格迁移 |

> **全场景 vs 局部的判断**：用户说"只改XX"、"仅XX区域"、"其他不动"时为局部；说"整体翻新"、"改成XX风格"、"全部换成"时为全场景。

## Step 2：生成 Prompt

根据领域 + 任务类型，选取对应模板，将用户的个性化需求（目标风格、改造区域、材质、色调等）融入占位符 `[...]`。

### 通用融合规则

1. 以模板为基础框架，**不删除"保持原有结构不变"等核心约束语句**
2. 将用户描述的风格/区域/材质/色调融入对应占位符
3. 用户未指定风格时，使用「现代简约风格」作为默认
4. 最终 prompt 使用**中文**输出

### 提示词模板库

#### 全场景风格翻新（1张实景图）

适用于所有三个领域（室内/建筑/景观）：

```
将这张[室内空间/建筑/庭院]的实景照片改造为[目标风格]效果图。保持原有空间结构与透视角度不变，对[家具软装及整体氛围/建筑立面材质及细节/植物配置及铺装]进行全面翻新：

[根据领域和风格，描述具体改造内容，包括：色彩方案、主要材质、家具/植物/立面风格、灯光氛围、软装配饰等关键要素]

光影：新生成的材质和元素需与原图的光照方向一致，阴影自然。
画质：8k 分辨率，照片级真实感，如同专业设计公司出品的翻新效果图。
```

#### 局部区域改造（1张实景图）

```
基于这张实景照片进行局部改造设计。
改造区域：[用户指定的区域，如阳台/背景墙/地面]。
要求：严格保持除改造区域外的其他部分完全不变，保持原有空间结构和透视关系。对[改造区域]进行[目标风格]的重新设计：
[描述改造区域的具体改造内容：材质、植物、家具、配色等]
光影：新生成的元素需与原图光照完美融合，阳光方向一致，无明显拼接痕迹。
画质：8k 分辨率，照片级真实感。
```

#### 参考图风格迁移（2张图）

```
让图1参考和学习图2中的色彩风格、材质质感和[灯光氛围/植物搭配/立面风格]。
要求：保持图1的空间结构、[墙体/建筑体块/场地布局]和透视完全不变，仅将图2的风格应用到图1中：
[列出从图2提取并应用到图1的关键风格要素：色彩体系、材质语言、家具/植物形态、灯光类型等]
使其成为一张生动而立体的翻新效果图。出图结果宽高比以图1为准。
画质：8k 分辨率，照片级真实感。
```

## 边界情况处理

| 情况                     | 处理方式                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 无法判断是全场景还是局部 | 默认全场景风格翻新                                                                                                         |
| 局部改造区域描述不清晰   | 直接询问：具体想改哪个区域？                                                                                               |
| 2张图但不确定哪张是底图  | 优先遵循 SKILL.md 多图角色识别结果；用户无声明时默认图1为实景底图、图2为风格参考图；声明与默认相反时必须在提示词中交换图号 |
