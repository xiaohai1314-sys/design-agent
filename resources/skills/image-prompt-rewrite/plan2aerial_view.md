# 建筑 / 景观 平面转鸟瞰图

## 核心理念

最终提示词 = **设计信息** × **表现风格**

- **设计信息**：从平面图识别到的客观要素（有无水体、水体是自然式还是规则式、有无儿童场、建筑数量层数、周边是否绘制等）。决定哪些非固定模块被启用，以及模块内部的具体措辞分支。
- **表现风格**：由用户指定或默认"真实"决定。决定每个模块的色彩、光线、质感、植被表达、人物表达等表现语言。
  两者正交：同一个"儿童活动场地"在真实风格下是彩色游乐设施的写实渲染，在概念竞赛风格下是钢蓝灰半透明色块叠加线稿。

## 工作流程

```
Step 1 判断领域（建筑 / 景观）
        │
Step 2 确认风格（默认真实，或用户指定 5 种之一 / 自定义风格）
        │
Step 3 识别平面图关键信息  ──► 确定启用哪些「非固定模块」及其子情况
        │
Step 4 查「风格表」 ──► 确定每个模块在该风格下的表现语言
        │
Step 5 按领域顺序拼装：固定模块 + 启用的非固定模块 ──► 输出最终提示词
```

### Step 1 领域判定

| 特征                                                                                   | 判定         |
| -------------------------------------------------------------------------------------- | ------------ |
| 建筑体量大，平面无景观细节或景观细节很少，以建筑轮廓为主                               | **建筑领域** |
| 绿化/水体/园路占比大、建筑小且分散、景观细节丰富（多种园路宽度、植被分层、景观节点等） | **景观领域** |

> **优先级规则**：只要平面图中存在以下任一特征，优先判定为**景观领域**——①曲线/蜿蜒园路体系；②多处景观节点（廊架、广场、儿童场、运动场等）；③丰富的植被分层；④水体与绿地占比显著。

### Step 2 风格确认

默认 **真实**；用户明确提及其他风格时切换。支持 5 种内建风格 + 自定义风格。
| 代号 | 名称 | 一句话定性 |
|---|---|---|
| S1 | 真实 | 高品质 MIR 风格写实 3D 渲染 |
| S2 | 清新 | 清新通透的建筑事务所方案渲染图 |
| S3 | 淡雅插画 | 暖奶油调低饱和手绘插画 |
| S4 | 活泼插画 | 白底+赤陶+青绿三色插画 |
| S5 | 概念竞赛 | 白底+藏蓝+橙金三色等轴测城市规划竞赛插画 |

> **自定义风格**：若用户指定风格不在以上 5 种（如夜景、水彩、轴测线稿、日式浮世绘等），不套用已有列，而是根据风格特征**动态推导**各维度表现语言，填入模块骨架。

### Step 3 平面图识别 → 设计信息提取

按以下清单逐项识别，**只描述实际存在的要素，禁止添加平面图未出现的设施**。
| 识别项 | 识别规则 | 决定的模块/分支 | 常见误判提醒 |
|---|---|---|---|
| 建筑元素 | 有无建筑、数量、大致位置、体量、可否识别层数 | 建筑元素模块（景观=配角 / 建筑=主体） | — |
| 道路铺装 | 只看平面图可见的路网（主园路、次路、消防环道、车道等）和广场铺装 | 道路与铺装模块 | 无消防环道则不写消防环道 |
| 停车/车库 | 仅在平面图有明确停车场或地下车库坡道符号时启用 | 道路与铺装模块的停车子项 | 不得默认小区有地下车库 |
| 水体类型 | 蓝色不规则曲线形 = 自然式水体；蓝色规则矩形+跑道线/设施图例 = **活动场地**（非水体）；蓝色规则矩形无跑道/设施图例 = 泳池/装饰水景 | 水体模块（自然式 / 规则式 / 两者并存） | 存疑时优先判为活动场地 |
| 草坪 | 大面积浅绿/深绿矩形或不规则绿色 = 草坪 | 景观元素模块 / 植被与绿地模块 | 绿色矩形 ≠ 水体/运动场 |
| 景观节点 | 儿童场、足篮球场、跑道、廊架、亭子、置石、雕塑、中心广场、入口广场等 | 景观元素模块（按实动态填写） | 有什么写什么，没有不编造 |
| 植被分层 | 乔木（深色树冠）、灌木带、草坪、地被色块分布 | 植被与绿地模块 | — |
| 周边环境 | 平面图边缘是否绘制周边建筑/道路/山体/河道 | 周边环境模块（按实 / 默认城市肌理） | — |

### Step 4 按风格查表

查下文「风格总表」确定各维度关键词，代入模块骨架的 `[占位符]`。

### Step 5 按领域顺序拼装

- **景观顺序**：固定开头 → 镜头构图 →景观元素 → 道路铺装 → 水体\* → 植被绿地 → 建筑元素 → 周边环境 → 光影氛围 → 成像要求
- **建筑顺序**：固定开头 → 镜头构图 → 建筑元素 → 道路铺装 → 水体\* → 植被绿地 → 周边环境 → 光影氛围 → 成像要求
  > \* 水体模块仅在平面图有水体时出现。

## 一、固定模块（仅风格驱动）

与平面信息无关，选定风格后即可确定。共 4 个：**固定开头、镜头构图、光影氛围、成像要求**。

### 1.1 固定开头（按领域分骨架，按风格填占位）

**景观骨架：**

```
根据提供的总平面图生成低空45度鸟瞰视角的景观[总体定性词]，要求与平面图的建筑、道路、绿化、水体、铺装等空间关系严格保持一致，不得改变设计布局。最终成像具备[质感描述]。
```

**建筑骨架：**

```
根据这张总平面图生成视角与地面夹角45度鸟瞰视角的建筑[总体定性词]。要求与平面图的建筑、道路、绿化、水体等空间关系严格保持一致，不得改变设计布局，最终成像具备[质感描述]。
```

> `[总体定性词]` 与 `[质感描述]` 从"风格总表"对应列取值。

### 1.2 镜头与构图（全风格通用）

```
广角镜头营造开阔空间感，画面完整呈现场景全貌及周边环境衔接。
```

### 1.3 光影氛围（按风格切换）

| 风格        | 文本                                                                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1 真实     | 光影与氛围：真实自然日光照明（上午或下午斜射光线），阳光温暖通透，树木与建筑投下清晰自然的阴影；远景城市轮廓与山体呈蓝紫色大气透视感，空间纵深感强。 |
| S2 清新     | 光影与氛围：柔和均匀的日光照明，高明度低饱和，阴影浅淡通透，画面干净清爽。                                                                           |
| S3 淡雅插画 | 光影与氛围：暖奶油色调漫射光，阴影以暖灰/暖褐色块简化表达，整体克制优雅，无强对比。                                                                  |
| S4 活泼插画 | 光影与氛围：明快通透的日光氛围，阴影极浅，白底突显赤陶与青绿主色，整体活泼跳跃。                                                                     |
| S5 概念竞赛 | 光影与氛围：无自然光影，以细密平行影线（hatching）和藏蓝色块表达阴影与层次，整体色调克制，三色对比强烈，叙事感强。                                   |

### 1.4 成像要求（骨架 + 风格填充）

**骨架：**

```
最终成像要求：画面比例 [比例]（默认16:9，用户指定优先），[成像质感末尾]。画面中不要出现红线、图例、文字标注、尺寸线、指北针等任何制图标注信息。
```

> `[成像质感末尾]` 从"风格总表"最后一行取值。

## 二、非固定模块（设计信息 + 领域 + 风格驱动）

共 6 个：**建筑元素、道路铺装、景观元素、水体、植被绿地、周边环境**。每个模块给出：①启用条件 ②领域分型骨架 ③风格适配方式。

### 2.1 建筑元素

**启用条件**：平面图存在建筑。
| 领域 | 骨架文本示例（S1 真实为基准） |
|---|---|
| 景观（配角） | 建筑表现：真实建筑材质呈现，可见屋顶瓦片/玻璃幕墙/木质表皮等细节，屋顶带有真实的光照阴影。 |
| 建筑（主体） | 建筑表现（重点）：建筑高度根据层数合理设置。建筑立面材质真实，可见窗户阵列、阳台、屋顶女儿墙等细节，立面崭新整洁。 |

**风格适配**：按风格总表"建筑风格"列替换材质与色彩描述。建筑领域在非真实风格下可弱化材质细节，强调体量关系。

### 2.2 道路与铺装

**启用条件**：始终启用（任何平面图都有路网）。停车子项按识别结果条件性启用。
| 领域 | 骨架文本示例（S1 真实为基准） |
|---|---|
| 景观 | 道路与铺装：主园路浅灰色沥青或混凝土，线形流畅蜿蜒，可见真实沥青颗粒质感；次级步道浅色透水砖、木栈道等多样材质；广场与集散空间真实铺装拼花纹理。 |
| 建筑 | 道路与铺装：城市道路真实沥青路面与车道划线，道路与消防环道清晰可见；人行道、广场以真实铺装材质表现 |
**条件性增补**：
| 识别到 | 追加描述 |
|---|---|
| 地面停车场 | 「停车场可见清晰车位线与停放车辆」 |
| 地下车库坡道入口 | 「地下车库坡道入口及出入口门洞结构」 |
| 无上述要素 | 不追加 |

**风格适配**：按风格总表"铺装风格"列替换。

### 2.3 景观元素（动态装配）

**启用条件**：仅景观领域启用。按平面图识别到的节点**动态拼装**，有什么写什么，不照抄全部。
| 识别到的要素 | 对应描述片段示例（S1 真实为基准） |
|---|---|
| 大草坪 | 中央大草坪开阔平整，草地翠绿，可见修剪纹理 |
| 儿童游乐区 | 儿童游乐场地配置彩色游乐设施，色彩活力 |
| 运动场（足/篮/跑道） | 运动场地清晰可见 |
| 廊架/亭子/构筑物 | 景观廊架/亭子以木质或金属材质呈现，可见结构细节 |
| 景观置石/雕塑 | 景观置石/特色雕塑作为视觉焦点点缀于节点处 |
| 入口广场/中心广场 | 入口广场/中心广场铺装精细，可见特色纹样与轴线引导 |
| 任意景观（通用补充） | 少量真实人物点缀，增强场景真实感与尺度感 |

**风格适配**：按风格总表"人物表现"列替换人物小品造型；小品造型按对应风格简化或抽象化（如 S5 概念竞赛中构筑物用钢蓝灰半透明色块+线稿表达）。

### 2.4 水体

**启用条件**：平面图识别出水体, **平面图中没有水体严禁在最终提示词中出现水体相关描述**
| 水体类型 | 骨架文本示例（S1 真实为基准） |
|---|---|
| 自然式（不规则曲线/自由形态） | 水体表现：自然式水体，水面呈深浅不一的蓝绿色调 |
| 规则式（矩形/几何形——泳池或装饰水景） | 水体表现：规则式装饰水景/泳池，水面清澈湛蓝，可见水底瓷砖纹理或镜面反光；驳岸以精切石材/混凝土压顶收边，边界线条利落整洁 |
| 两者并存 | 分别描述两段自然式与规则式水体 |

**风格适配**：按风格总表"水体风格"列替换。

### 2.5 植被与绿地

**启用条件**：始终启用。

## 三、输出规范

1. **只输出一段完整提示词**，不分段不加标题，长度以覆盖所有启用模块为度。
2. **全中文输出**，专有名词可保留英文。
3. **不出现引导语**（"这展示了""我为您生成了"等）。
4. **比例参数**：默认 16:9，用户指定优先。

## 四、边界与注意事项

1. **用户已有提示词**：按照模块分类添加到对应的模块中
2. **超出五种内建风格**（夜景、水彩、日式、轴测线稿等）：按"自定义风格"流程动态推导各维度表现语言，填入骨架。
3. **禁止凭空添加设施**：水体等必须在平面图中有明确对应图示才能写入，否则一定要删除相关水体描述！！！
