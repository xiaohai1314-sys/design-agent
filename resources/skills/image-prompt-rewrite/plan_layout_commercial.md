# 工装平面布局设计提示词生成

## 整体流程

```
用户上传户型图 + 可选文字描述 + 对话上下文
       ↓
Step 1: 提取功能分区、布局陈设、分区逻辑与动线
       ↓
Step 2: 确认出图风格（默认黑白CAD线稿风格）
       ↓
Step 3: 拼装最终提示词
```

## Step 1：提取功能分区、布局陈设、分区逻辑与动线

从用户文字描述及当前对话上下文中，提取与**功能分区、动线说明、空间布局、设备/软装陈设**相关的内容。

### 提取规则

| 规则                       | 说明                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 保留内容                   | 功能分区（如：公共卫生间、门厅、电梯井道、机控室、厨房、就餐区、办公区等）；动线说明（如：厨房靠左侧、客流上方进入、传菜线与客流线不交叉）；空间方位与相邻关系（如：西北位楼梯间后方、电梯后方、门厅后方、旁侧）；明确尺寸（如：电梯外包2600\*2200、机控室20㎡）；容纳量（如：50人就餐区）；原有结构的保留/改造（如：保留原尺寸公共卫生间、原有门洞进出）；门窗开向（如：门外开）；设备与软装陈设 |
| 删除内容                   | 所有风格描述（现代、工业、新中式等）、色彩描述、材质描述、氛围类词汇                                                                                                                                                                                                                                                                                                                              |
| 分区逻辑                   | 从用户已表述的内容/上下文中提炼功能区组织逻辑——如用户说的"左边书吧、中间服务台、右边健身"本身就是"从左到右"的分区逻辑。仅当用户完全没有任何方位、顺序、相邻线索时，才结合底图形态与功能性质归纳一条合理逻辑，作为统领下文功能陈设描述的主线                                                                                                                                                       |
| 动线说明                   | 在功能描述之外，单独提炼**一句**动线说明：如：何者居中衔接/分流、卫生间/换衣间等辅助用房就近服务谁等。优先复述用户已给的动线要求，若无则据分区逻辑合理补**一句**，写入 `[动线说明]`                                                                                                                                                                                                               |
| 陈设补充                   | query 只给出功能名而未列家具时，克制补充核心家具作为视觉锚点，每区只取最具代表性的 1–2 件，能少则少（如：书吧→通高书架+阅读桌；器材区→器械成组），仅列家具清单不做家具样式描述。补充须符合常识、不与 query 冲突。当 query 已自带家具清单或描述时，原样沿用、不再叠加扩充                                                                                                                          |
| 贴合底图措辞               | 描述功能与衔接时优先复述底图真实可见的结构元素（洞口、电箱、原有柜台、楼梯口等）作为定位与衔接锚点，少用抽象概念词；涉及改造时如实写"在原有 X 基础上精简/保留"（如"原柜台基础上精简掉5节"），引导模型贴合现状                                                                                                                                                                                     |
| 归入特殊要求               | 非分区但属硬性约束的描述（如：符合5A景区标准、商务稳重、隔音、采光朝向要求），不删除，写入 `[用户特殊要求]`                                                                                                                                                                                                                                                                                       |
| 尺寸与容量                 | 凡 query 中出现的尺寸、面积、容纳人数，**必须原样保留**，不得省略/改写                                                                                                                                                                                                                                                                                                                            |
| 字数限制                   | 总结后控制在 **150字以内**，功能、方位与尺寸信息优先                                                                                                                                                                                                                                                                                                                                              |
| 无任何功能/布局/动线信息时 | 不进行抽取，按 Step 3 默认布局生成，并在回复中引导用户补充，**严禁自行编造 query 中没有的功能或房间**                                                                                                                                                                                                                                                                                             |

### 提取示例

原 query（摘录）：

> 西北位公共楼梯间后面保留原有尺寸公共卫生间，门还是外面开。原有门洞进出门厅 后面留个井道电梯外包尺寸2600\*2200 电梯后面做个20平方的机控室，边上是一个厨房以及50人左右就餐区

提取后（聚焦功能、方位、尺寸、容量、软装陈设，去除冗余口语，补上一句动线说明）：

> 西北侧公共楼梯间后方保留原尺寸公共卫生间（门外开）；原有下侧门洞进出门厅；门厅后方设井道电梯（外包尺寸2600×2200）；电梯后方设20㎡机控室；旁侧设厨房（成组灶台与操作台）及约50人就餐区（成组餐桌椅）。客流由门厅进入就餐区，厨房紧邻就餐区出餐就近，竖向交通与设备用房集中后部不干扰用餐。

## Step 2：确认出图风格

| 情况         | 出图风格                           |
| ------------ | ---------------------------------- |
| 用户未指定   | 黑白CAD线稿风格（默认）            |
| 用户指定风格 | 使用用户指定的描述（如淡彩风格等） |

## Step 3：拼装最终提示词

### 模板骨架（完整段落式）

```
请基于这张[xxx项目]的原始户型图，生成一张专业的室内平面布置方案，2D俯视正投影视角；首先严格沿用底图既有的墙体、立柱、楼梯、电梯、卫生间、管道井与门窗洞口位置，不新增、不挪动、不拆改任何结构，不新增/改变出入口，仅在现有空间内做软性分区与家具排布。[功能分区、相邻关系及家具陈设内容]。动线上，[动线说明]，所有通道连贯顺畅，功能分区明确合理；[用户特殊要求]；请清晰表达家具陈设与地面铺装的边界，比例真实、线条干净规范，各功能区用简洁中文标注空间名称，整体采用[出图风格]，呈现一份干净、专业、可直接汇报的室内平面布置图。
```

### 各占位符填写规则

| 占位符                               | 填写内容                                                                                                                                                                                                                                                                                       |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[xxx项目]`                          | 项目类型/名称（如：5A级景区游客集散中心、餐饮配套空间）；不明确时写"工装空间"                                                                                                                                                                                                                  |
| `[功能分区、相邻关系及家具陈设内容]` | Step 1 提取并已陈设具体化的功能内容（150字以内）。须顺着 [分区逻辑] 的语序与因果展开——每个功能区出现的先后、相邻与原因都由分区逻辑串起（如"门厅之后纵向集中交通与设备……就餐紧邻厨房使出餐最短"）；陈设按"克制补充"规则描述；若无任何信息，删除本占位符，并将前句改为"在现有空间内合理布置功能" |
| `[动线说明]`                         | Step 1 单独提炼的那一句动线说明（谁居中分流、动静/洁污如何不交叉、辅助用房就近服务谁等）；若无功能信息可省略本句                                                                                                                                                                               |
| `[用户特殊要求]`                     | Step 1 归入特殊要求的硬性约束（品质定位、隔音、朝向、容纳人数等）；若无则删除本占位符及其前后的"；"                                                                                                                                                                                            |
| `[出图风格]`                         | Step 2 确认的风格，默认为"黑白CAD线稿风格"                                                                                                                                                                                                                                                     |

注意：Step 1 提炼的分区逻辑作为组织原则，优先复述用户已表述的布局意图（如"用户所述左—中—右从左到右"）；用户无任何线索时才填合理推断。它是统领下文功能陈设的主线，不是孤立的一句——后续 [功能分区…内容] 顺着这条逻辑的语序与因果来写。

### 拼装示例

**示例 A — 人才公寓公共配套（有功能、无尺寸、默认风格）：**

> 请基于这张人才公寓公共配套区的原始户型图，生成一张专业的室内平面布置方案，2D俯视正投影视角；首先严格沿用底图既有的墙体、立柱、楼梯、电梯、卫生间、管道井与门窗洞口位置，不新增、不挪动、不拆改任何结构，不改变/新增出入口，仅在现有空间内做软性分区与家具排布。整体按"左—中—右、从静到动"展开：左侧独立区域设共享书吧（沿墙通高书架、单人阅读桌与软座卡座），中部设服务台与咖啡吧（接待咨询台、咖啡制作吧台、吧台高凳与休闲洽谈桌椅），右侧大空间为健身娱乐区，利用既有隔墙分隔器材区（有氧与力量器械成组）、台球室（台球桌居中、四周留够走位）与独立瑜伽室（地面铺垫、靠墙镜面），角落就近设男女卫生间及对应换衣间。动线上，书吧静区与健身动区分置两端互不干扰，服务台咖啡吧居中衔接并分流人流，卫生间换衣间紧邻健身区方便更衣，所有通道连贯顺畅，功能分区明确合理。请清晰表达家具陈设与地面铺装的边界，比例真实、线条干净规范，各功能区用简洁中文标注空间名称，整体采用黑白CAD线稿风格，呈现一份干净、专业、可直接汇报的室内平面布置图。

**示例 B — 默认布局（仅上传图片、无任何功能信息、默认风格）：**

> 请基于这张工装空间的原始户型图，生成一张专业的室内平面布置方案，2D俯视正投影视角；首先严格沿用底图既有的墙体、立柱、楼梯、电梯、卫生间、管道井与门窗洞口位置，不新增、不挪动、不拆改任何结构，不改变/新增出入口，仅在现有空间内合理布置功能、做软性分区与家具排布；动线连贯顺畅，功能分区明确合理。请清晰表达家具陈设与地面铺装的边界，比例真实、线条干净规范，各功能区用简洁中文标注空间类型，整体采用黑白CAD线稿风格，呈现一份干净、专业、可直接汇报的室内平面布置图。

## 输出规范

1. 全中文输出，专有名词与尺寸可保留英文/数字。
2. 仅输出一段完整提示词，不分段、不加标题、不写引导语。
3. query 中的尺寸、面积、容纳人数必须原样写入，确保电梯井道、设备间、就餐区等关键数据不被省略。
4. 务必包含三要素：① 锁定原结构的指令；② 用逻辑串联的功能布局 + 简洁家具陈设描述；③ 单独一句动线说明。
5. 不出现东南西北方位词，全部用上下左右描述，若用户query出现东南西北，结合底图（锚点分区或指北针等）对用户用词进行转化，转化为上下左右。

## 回复规范

- 调用生图前简要告知："识别到这是一张**工装**户型图，将为您生成**[出图风格]**的平面布局图。"
- 如结果不满意，引导用户补充：各区域功能需求、设备/房间尺寸、容纳人数、相邻关系与动线、原有结构保留情况等。

## 边界情况处理

1. **用户仅上传图片无文字**：无功能/布局信息可提取，使用默认风格，按示例 C 生成基础功能分区，并在回复中提示用户补充具体功能需求与尺寸。
2. **query 含明确尺寸/容量**：必须原样写入提示词（参见示例 B）。
3. **用户要求基于已有完整平面填彩**：非本场景，路由至 `colorplan`。
4. **用户要求生成效果图/鸟瞰图/三维表现**：非本场景，按主 SKILL 重新路由。
