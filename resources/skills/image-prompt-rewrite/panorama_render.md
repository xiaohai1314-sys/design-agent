# 全景渲染（Panorama Render）

## 适用领域

**仅支持家装（home）和工装（commercial）**。建筑、景观领域直接走 Fallback。

## 整体流程

```
用户上传鱼眼圆柱投影图（必须）+ 文字描述需求
        ↓
Step 1：解析用户需求
        ↓
Step 2：融合用户需求 → 生成最终 Prompt
        ↓
Step 3：调用图像生成工具，展示结果并引导迭代
```

## Step 1：解析用户需求

从用户文字中提取以下信息，供 Step 2 填入模板：
| 信息项 | 提取方式 | 默认值（未指定时）|
|--------|----------|-----------------|
| 风格 | 用户描述中的风格词 | 现代风格，注重光影层次 |
| 材质 / 色彩 | 用户提及的材质、色调偏好 | 无额外追加 |
| 氛围 / 特殊要求 | 用户的其他描述 | 无额外追加 |
| 出图比例 | 用户明确指定时记录 | 2:1（全景标准比例） |

## Step 2：生成 Prompt

### 融合规则

1. 将 Step 1 提取内容完整填入 `[用户的需求]` 占位符，**不得删减或笼统化**
2. 不删除质量控制语句（8k、V-Ray、出图比例）
3. 用户明确指定出图比例时，以用户要求覆盖模板中的「2:1」
4. 最终 prompt 使用**中文**输出，专有名词可保留英文
5. 严禁添加补充用户文字描述需求之外的内容

### Prompt 模板

```
基于这张草图/模型截图生成专业级别的渲染效果图。
要求：严格保持原有的空间结构、墙体位置和透视关系不变。在此基础上，添加真实的材质纹理（地板、墙面、家具），生成专业的灯光光影效果，营造空间立体感。
[用户的需求]。画质：8k 分辨率，照片级真实感，V-Ray 渲染质感。出图比例严格控制为2:1。
```
