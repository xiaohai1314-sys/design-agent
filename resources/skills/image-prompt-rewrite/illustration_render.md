# 插画风效果图提示词生成

## 流程

```
用户输入（文字 + 可选图片）
       ↓
Step 1：场景判断（建筑/规划、景观、家装、工装）
       ↓
Step 2：视角判断（鸟瞰、半鸟瞰、轴测、透视、立面）
       ↓
Step 3：推断风格模板（A 水彩 / B 矢量扁平 / C 单色高饱和 / D 线稿拼贴 / 自定义）
       ↓
Step 4：提示词结构化选取
       ↓
Step 5：提示词结构化构建
       ↓
输出最终中文 prompt
```

## Step 1：场景判断

| 场景          | 判断依据                                                                   |
| ------------- | -------------------------------------------------------------------------- |
| **建筑/规划** | 建筑单体、建筑群、城市设计、街区规划、总平、鸟瞰模型、体块推演、规划分析图 |
| **景观**      | 公园、广场、庭院、绿地、水体、栈道、儿童活动场、景观节点、滨水空间         |
| **家装**      | 住宅室内、客厅、餐厅、卧室、厨房、书房、阳台、软装搭配                     |
| **工装**      | 商业空间、办公室、咖啡馆、书店、酒店、展厅、餐饮、零售、公共室内           |

## Step 2：视角判断

| 视角       | 判断依据                                                   |
| ---------- | ---------------------------------------------------------- |
| **鸟瞰**   | 高角度俯视，屋顶、路网、场地边界清晰，人物车辆很小         |
| **半鸟瞰** | 介于鸟瞰和人视之间，可见屋顶也可见立面，有明显透视         |
| **轴测**   | 等轴测或近似轴测，无明显透视消失点，常见于模型截图、分析图 |
| **透视**   | 人视或近人视，有消失点，强调空间进入感                     |
| **立面**   | 正立面、沿街立面、室内墙面展开、剖立面，无明显透视         |

## Step 3：推断风格模板

关键词命中优先；无关键词则根据场景和视角推断；均无法判断时默认 B。
| 风格 | 触发关键词 | 核心特征 |
|------|-----------|---------|
| **A 水彩拼贴风** | 水彩、水彩拼贴、水彩插画、watercolor | 水彩晕染、纸面颗粒、柔和光影、拼贴层次感，原图已有的人物植物可带白色轮廓线 |
| **B 矢量扁平风** | 扁平、矢量、矢量插画、flat、编辑插画 | 高饱和互补色对比（暖橙/黄/木色 vs 冷青蓝/蓝绿）、强方向日光、几何平涂阴影、每面2-3近似色叠加光影层次、无描边无线稿、丝网印刷颗粒质感、中世纪编辑插画风，人物仅在原图已有或用户要求时出现 |
| **C 单色/双色高饱和** | **概念**、Risograph、单色、双色、高饱和、竞赛图、概念图、概念插画 | 1~2种高饱和对比色上色、其余区域白/米白留白、高对比强反差、可加Risograph颗粒 |
| **D 线稿素材拼贴** | 线稿、CAD线稿、拼贴、素材拼贴、分析图、竞赛图 | 冰蓝条纹底图、原有植被铅笔线稿、少量必要白色人物剪影、珊瑚橙红点缀色、半透明填色与原有材质纹理 |

**自定义风格：** 若用户指定风格不在以上 4 种（如夜景霓虹、日式浮世绘、赛博朋克、水墨等），不套用已有列，根据风格特征动态推导色调、线条、质感、光影、人物处理方式，填入 Step 5 骨架。

## Step 4：提示词片段库

### 主体 + 配景（按场景）

**建筑/规划**

```
主体：以图中的建筑/规划主体为核心，严格保留建筑体量、屋顶轮廓、立面比例、开窗节奏和视角空间关系，不改变原图构图；同时必须严格还原原图的场地要素，包括道路、人行道、车行道、广场、铺装、绿地、草坪、原有乔木/灌木/地被等植物配景，植物的种类、形态、数量、位置不得随意改变。
配景：天空、云、太阳等氛围元素可根据原图氛围适度补充；不主动新增原图不存在的人物、车辆、家具、设施——原图无人物时不得加人，原图无车辆时不得加车，原图已有则保留并尊重原数量与位置；仅用户明确要求时才增加道路标注、功能区色块、动线箭头等分析性内容。
```

**景观**

```
主体：以图中的景观主体为核心，严格保留场地边界、路径结构、水体/草坪/铺装关系、主要构筑物和植物层次，不改变原有视角和空间组织；必须充分还原原图的植物种类、形态、特征、数量和位置，景观特色（如廊亭、水景、栈道、汀步等）必须按原图准确呈现，不得简化或替换。
配景：仅在原图已有元素基础上轻微强化乔木、灌木、地被的层次和铺装/水面细节；不主动新增人物、座椅、灯具、构筑物等元素——原图无人物时不得增加人物，原图无水景时不得新增水景，原图无座椅家具时不得增加家具；如原图已有少量人物可保留，但数量、位置、姿态需与原图一致，不得堆砌人群。
```

**家装**

```
主体：以图中的家装空间为核心，严格保留墙体、门窗、主要家具布局、软装主色、原有材质纹理和采光方向，不改变住宅空间尺度；原图已有绿植需保留位置、数量和形态，不新增植物景观。
配景：只在原图基础上轻微强化地毯、挂画、书籍、抱枕、布艺纹理、木纹、石材或墙面肌理等生活细节，不主动增加人物，不堆叠额外摆件，不遮挡或替换原有家具与装饰。
```

**工装**

```
主体：以图中的工装空间为核心，严格保留功能分区、空间动线、柜台/展陈/座位布局、品牌界面、原有材质纹理和照明关系，不改变商业或办公空间逻辑；原图已有绿植需保留位置、数量和形态，不新增植物景观。
配景：只补充少量必要的运营氛围元素，如原图已有的商品陈列、导视标识、灯光层次和材质肌理；人物仅在原图已有或用户明确要求时少量保留/弱化，不新增密集顾客或员工，不遮挡柜台、展陈、座位、家具和装饰。
```

### 视角（按视角）

| 视角   | 提示词片段                                                               |
| ------ | ------------------------------------------------------------------------ |
| 鸟瞰   | 保持高角度俯视关系，清晰呈现屋顶、场地边界、绿化和主要节点分布。         |
| 半鸟瞰 | 保持半鸟瞰透视关系，同时呈现屋顶、立面和前中后景层次，主体空间关系不变。 |
| 轴测   | 保持等轴测投影和体块关系，无透视失真，所有元素按原有轴测角度表达。       |
| 透视   | 保持人视或近人视透视关系，保留相机高度、消失点、主体轮廓和空间纵深。     |
| 立面   | 保持正立面或二维展开构图，保留门窗比例、层高关系和界面分区。             |

### 风格（按风格）

| 风格              | 提示词片段                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A 水彩拼贴风      | 水彩插画拼贴风格，水彩晕染需克制适度，不可过度湿润或大面积晕染覆盖结构；以钢笔细线稿作为骨架支撑主体轮廓和细节，水彩仅作为线稿上的着色层；纸面颗粒质感，温暖自然光，色彩明亮通透，前中后景带轻微拼贴层次，原图已有的人物与植物可带细微白色轮廓线。严格保留原图所有元素及其空间关系——建筑/景观/人物/家具/栏杆/植物/铺装/水体（或无水体）的位置、数量、形态和相互遮挡关系不得改动；不得新增原图不存在的水景、湖面、池塘等元素；人物必须严格位于原本位置，不得穿模、不得脱离栏杆/座椅/墙体等结构。整体有手绘效果但保持透视准确、结构清晰。画面不得出现水印、LOGO、文字标识、签名或网站地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| B 矢量扁平风      | 矢量扁平插画风格，色彩饱和明快，以橙/暖黄/棕木等暖色与青蓝/蓝绿等冷色形成高对比互补关系；强方向性日光处理，光区留白或奶白，阴影为同色系深色几何色块，投影边缘干净清晰；每个物体以两至三个邻近色调的平涂色块叠加表现光影层次，不使用渐变；木质地面以温暖横向条纹表现；植物叶形几何简化、色彩饱满；整体呈现中世纪现代主义编辑插画质感，视觉张力强；表面叠加轻微丝网印刷颗粒噪点；无描边，无手绘线稿；人物仅在原图已有或用户明确要求时少量保留并扁平化处理。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| C 单色/双色高饱和 | 单色/双色高饱和风格化插画，选取高对比互补色对图像进行上色，其余区域保持白色或米白留白，高对比强反差，图形化色块构成，可叠加 Risograph 粗颗粒质感，整体具有编辑海报感。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| D 线稿素材拼贴    | 线稿素材拼贴风格。背景可使用冰蓝色/浅灰蓝竖向细条纹底图（类格纸纹理）。建筑或室内主体以钢蓝色细线稿勾勒轮廓，局部填浅色半透明色块，整体保持通透轻盈感。家装/工装场景的木纹、石材、布艺、金属、墙面、地面等材质必须保留并以矢量化贴图质感处理——保留材质原有色相与纹理特征，简化为清晰的矢量图层感，不替换为统一平涂色块，也不直接保留照片质感。植被仅按原图已有内容以精细铅笔手绘线稿表现，保留位置、数量和层次，不新增植物景观。人物为少量纯白剪影/白色轮廓线，不填色，不喧宾夺主。画面可点缀少量珊瑚橙红色作为强调色，如铺装、局部标注或细小装饰符号。建筑室外/景观线稿拼贴可根据原图和氛围加入天空元素：太阳为适中尺寸的桃色/浅橙圆形，不宜过大，占天空区域约1/8以内，带轻微晕染感；云朵以白色精细线稿勾勒，数量充足、形态饱满，以细线轮廓叠加轻微排线表现体积感，整体与线稿风格统一，避免纯水彩晕染或模糊色块感；飞鸟为白色三角形/箭头形抽象剪影，成群分布；三者均需与整体线稿色调协调，线条精细清晰。建筑结构与景观主体轮廓线精细锐利、层次丰富；填色饱和度适当提高，偏蓝紫半透明色调，珊瑚橙红铺装与点缀饱和度高、对比鲜明；可适当加入珊瑚红十字或星形装饰符号点缀。家装/工装室内线稿拼贴避免主动加入此类室外天空元素。整体轻盈、通透，主体关系清晰。 |

## Step 5：提示词结构化构建

按以下顺序拼合各片段，不得保留任何方括号占位符：

```
[主体片段] [配景片段] [视角片段] [风格片段] [用户补充的色调/季节/氛围/特定元素] 高细节，构图完整，主体清晰。
```

## 输出规范

1. **仅输出一段完整的提示词**，内容用逗号连贯拼接，不分段、不加标题。
2. **全中文输出**，专有名词可保留英文。
3. **不写废话**：不要出现"这展示了"、"我为您生成了"等引导语。
