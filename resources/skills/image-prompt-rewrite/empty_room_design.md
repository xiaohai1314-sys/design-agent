# 毛坯精装设计（Empty Room Design）

## 整体流程

```
用户上传毛坯室内照片（1张或2张）+ 描述风格/业态需求
        ↓
Step 1：判断领域 × 任务类型 × 风格
        ↓
Step 2：选取风格模板 → 融合用户需求 → 拼装最终 prompt
        ↓
Step 3：告知判断结果，输出最终 prompt，调用生图工具
```

## Step 1：判断领域、任务类型与风格

### 1.1 领域判断（用于补充家具与陈设语义）

| 领域     | 触发依据                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **家装** | 用户提到客厅、卧室、餐厅、书房、卫生间、厨房、阳台等；或毛坯空间体量为住宅尺度                                                                        |
| **工装** | 用户提到办公室、写字楼、会议室、酒店大堂/客房、餐厅（商业）、咖啡馆、展厅、商铺、专卖店等；用户未指定空间类型是，如果毛坯空间体量较大，倾向判断为工装 |

### 1.2 任务类型判断

| 图片数量                                                                                                         | 用户意图                     | 任务类型               |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------- | ---------------------- |
| **1 张毛坯图** + 风格描述（含内置风格名"现代/简约欧式/新中式/日式"，或自定义风格如"工业风""ins 风""赛博朋克"等） | 组装单图风格模板             | `custom_style`         |
| **2 张图**（图1=毛坯底图，图2=风格参考图）                                                                       | 按图2风格装修图1，可指定领域 | `reference_renovation` |

### 1.3 内置风格关键要素表

当用户指定以下四种内置风格名时，按本表查表填入 `custom_style` 模板中的"风格关键要素"段落（色调 + 材质 + 家具 + 氛围四要素必须全部覆盖）：

| 风格         | 色调                                           | 材质                                                    | 家具                                             | 氛围                                       |
| ------------ | ---------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| **现代**     | 中性基调：白、灰、米色为主                     | 天然木饰面、哑光乳胶漆                                  | 线条简约流畅的家具                               | 宽敞、明亮、通透，干净利落的高级感         |
| **简约欧式** | 浅色为主：米白、奶咖、浅灰，少量金色或木色点缀 | 装饰线框墙板、简约石膏线、原木地板、布艺软包            | 古典轮廓但去繁就简的舒适沙发与餐椅，融合现代比例 | 优雅、轻松、温润，古典框架下的现代舒适感   |
| **新中式**   | 原木色 + 黑白灰基底                            | 深色木格栅、月亮门/窗棂、棉麻丝绸软装、青砖或微水泥墙面 | 线条简练的实木家具，低背圈椅、案几，对称式布局   | 宁静、风雅、留白美学，富文化底蕴的东方意境 |
| **日式**     | 白色 + 浅木色为主，少量原麻、灰调点缀          | 浅色橡木/杉木地板、障子门/格栅、和纸灯具、榻榻米        | 低矮家具，线条更现代但保留禅意，注重收纳与留白   | 开阔、整洁、宁静，功能性中透出侘寂美学     |

## Step 2：拼装 Prompt

### 通用结构（所有任务类型共享）

```
[任务指令] + [领域/空间类型] + [风格关键要素描述] + [毛坯保留约束] + [画质收尾]
```

### 通用核心约束（按底图洞口情况二选一，非常重要！！！）

**组装提示词前，先视觉核查底图是否存在窗洞，再选用对应收尾约束：**

- **底图存在窗户** → 使用：
  ```
  保证原空房间的窗洞位置、大小、形态、比例完全不变，不得封闭或缩小任何洞口，保持视角不变。
  ```
- **底图没有任何窗户** → 改用：
  ```
  原空房间墙体结构大小、形态、比例、逻辑完全不变，保持视角不变。
  ```
  模板正文中所有形如"保证原空房间室内的窗洞和门洞位置、大小、形态、比例完全不变……保持视角不变。"的句子，均按上述规则替换为对应版本。
- 参考图装修任务（`reference_renovation`）需额外追加：
  ```
  输出图1比例的画幅。
  ```

### 融合规则

1. 模板中的 `[空间类型]` 占位符按领域对应的空间类型填入：客厅 / 卧室 / 餐厅 / 办公室 / 酒店大堂 / 卫生间 / 商铺等
2. 模板中的 `[风格关键要素]` 段落必须保留风格定义中的**核心元素**（色调、材质、家具、氛围四要素）
3. 用户额外指定的色调、材质、植物、装饰偏好直接追加到风格关键要素段落
4. 用户未指定风格且无法推断时，默认 `modern`

## 提示词模板库

### 任务类型 A：`custom_style`（单图风格化 · 1张毛坯图）

```
将这张空房间照片改造成[风格名]风格的[空间类型]，保持画面结构逻辑和视角不变。[风格关键要素：覆盖①色调与配色方案；②主要墙地顶材质与立面工艺；③家具/灯具/软装的造型语言；④整体氛围与光感，控制在100字以内]。家具与陈设需与空间尺度协调，材质与光影自然，呈现专业级精装效果，写实室内摄影，质感通透。[用户附加要求，如有]保证原空房间室内的窗洞位置、大小、形态、比例完全不变，不得封闭或缩小任何洞口。保持视角不变。
```

> **风格关键要素填写规则**：
>
> - 用户指定的是**内置风格**（现代/简约欧式/新中式/日式）→ 参考按"1.3 内置风格关键要素表"将色调、材质、家具、氛围四要素串联成一句话填入，家具需根据空间类型动态推演；
> - 用户指定的是**自定义风格**（如"工业风"）→ 自动展开四要素，例如"工业风" → "深灰、黑、铁锈红色调；裸露混凝土、红砖、黑铁金属管线；皮革沙发与铸铁灯具；冷峻、原始、粗犷氛围"。

### 任务类型 B：`reference_renovation`（参考图装修 · 2张图）

```
将图1的空房间照片装修成[业态/空间类型，如酒店餐厅/精品酒店客房/会议室/西餐厅等]，保持画面结构逻辑和视角不变，装修风格参考图2，家具与陈设需与空间尺度协调，材质与光影自然，呈现专业级精装效果，写实室内摄影，质感通透。[用户附加要求，如有]输出图1比例的画幅，保证原空房间室内的窗洞位置、大小、形态、比例完全不变，不得封闭或缩小任何洞口，保持视角不变。
```

## 边界情况处理

| 情况                             | 处理方式                                                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 用户上传毛坯图但完全没有文字描述 | 默认 `custom_style` + 内置`现代`风格，业态按毛坯尺度推断                                                                   |
| 用户描述了风格但未说明业态       | 按毛坯图体量推断业态；无法推断时默认家装客厅                                                                               |
| 2张图但不确定哪张是底图          | 优先遵循 SKILL.md 多图角色识别结果；用户无声明时默认图1为毛坯底图、图2为风格参考图；声明与默认相反时必须在提示词中交换图号 |
